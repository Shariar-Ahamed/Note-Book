## 🎯 Production Standards ([Rulebook](.AGENT/agent.md))

- **100% Zero-Skipping Policy:** All definitions, modules, edge cases, tables, ASCII diagrams, and practice problems are rendered verbatim.
- **Page 1 Balance:** Master Banner + Chapter Intro + Part 01 Banner + Section 1 Card fit unbroken on Page 1.
- **Zero Mid-Card Page Splits:** Strict CSS page-break rules preventing code or study cards from splitting across pages.
- **Precision Print Margins:** A4 format with `@page { size: A4; margin: 8mm 10mm; }`.
- **Overflow Prevention:** Code blocks and ASCII trees with auto-wrap to eliminate horizontal scrollbars in print.
