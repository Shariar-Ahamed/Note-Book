# 23.1 Regular Expression কী?

**Regular Expression বা Regex** হলো একটি pattern language।

সহজভাবে:

> কোনো text-এর মধ্যে নির্দিষ্ট ধরনের pattern খোঁজা বা যাচাই করার নিয়ম হলো Regular Expression।

ধরো:

```text
Hello Shariar
Hello Rahim
Hello Karim
```

তুমি যদি এমন text খুঁজতে চাও যেটা:

```text
Hello + একটি নাম
```

তাহলে Regex pattern ব্যবহার করতে পারো।

# 23.2 Real-Life Example

```text

```

abc@xyz.com

তুমি check করতে চাও:

Output:

```text

```

এখন:

# 23.7 গুরুত্বপূর্ণ Regex Flags

| Flag | কাজ                                 |
| ---- | ----------------------------------- |
| `i`  | Case-insensitive                    |
| `g`  | Global search                       |
| `m`  | Multiline                           |
| `s`  | Dot যেন newline-ও match করতে পারে   |
| `u`  | Unicode-aware matching              |
| `y`  | Sticky matching                     |
| `d`  | Match indices তৈরি করতে সাহায্য করে |

Example:

```javascript
/hello/gi;
```

মানে:

```text
g → সব match
i → case-insensitive
```

`g` না দিলে:

# 23.30 Capturing Groups

Regex-এর একটি অংশ আলাদা করে capture করতে পারো।

```javascript
const regex = /(\d{4})-(\d{2})-(\d{2})/;

const result = "2026-09-16".match(regex);

console.log(result);
```

Conceptual output:

```text
[
    "2026-09-16",
    "2026",
    "09",
    "16"
]
```

এখানে:

```text
Group 1 → 2026
Group 2 → 09
Group 3 → 16
```

---

# 23.31 Non-Capturing Group

যদি grouping দরকার কিন্তু capture দরকার না হয়:

```regex
(?:...)
```

Example:

```javascript
const regex = /(?:cat|dog)/;
```

এটি group করবে, কিন্তু capturing group তৈরি করবে না।

---

# 23.32 Named Capturing Groups

আরও readable করার জন্য group-এর নাম দেওয়া যায়।

```javascript
const regex = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;

const result = "2026-09-16".match(regex);

console.log(result.groups);
```

Output:

```javascript
{
    year: "2026",
    month: "09",
    day: "16"
}
```

এটা advanced কিন্তু real-world parsing-এ useful।

# 23.33 Backreference

Captured group পরে আবার একই text match করতে ব্যবহার করা যায়।

Example:

```javascript
const regex = /\b(\w+)\s+\1\b/i;

console.log(regex.test("hello hello"));
```

Output:

```text
true
```

এখানে:

```text
(\w+)
```

প্রথম word capture করেছে।

```text
\1
```

মানে:

> Group 1-এ যে text ছিল, সেটিই আবার আসতে হবে।

# 23.34 Lookahead

Lookahead pattern-এর পরের অংশ check করে কিন্তু consume করে না।

### Positive Lookahead

```regex
X(?=Y)
```

মানে:

> X-এর পরে Y থাকতে হবে।

Example:

```javascript
const regex = /\d+(?= USD)/;

console.log("100 USD".match(regex));
```

Output:

```text
["100"]
```

---

# 23.35 Negative Lookahead

```regex
X(?!Y)
```

মানে:

> X-এর পরে Y থাকা যাবে না।

Example:

```javascript
const regex = /foo(?!bar)/;

console.log(regex.test("foobar"));
```

Output:

```text
false
```

কিন্তু:

```javascript
console.log(regex.test("foobaz"));
```

Output:

```text
true
```

---

# 23.36 Lookbehind

Lookbehind সামনে নয়, আগের অংশ check করে।

### Positive Lookbehind

```regex
(?<=X)Y
```

Example:

```javascript
const regex = /(?<=\$)\d+/;

console.log("$100".match(regex));
```

Output:

```text
["100"]
```

---

# 23.37 Negative Lookbehind

```regex
(?<!X)Y
```

মানে:

> Y-এর আগে X থাকা যাবে না।

Example:

```javascript
const regex = /(?<!\$)\d+/;

console.log("USD 100".match(regex));
```

এখানে `100` match হতে পারে কারণ এর আগে `$` নেই।

# 23.38 Greedy Matching

Regex quantifier সাধারণত greedy।

মানে:

> যত বেশি সম্ভব text match করতে চেষ্টা করে।

Example:

```javascript
const text = "<b>Hello</b><b>World</b>";

console.log(text.match(/<b>.*<\/b>/));
```

এখানে `.*` অনেক বেশি text consume করতে পারে।

---

# 23.39 Lazy Matching

Lazy করতে `?` ব্যবহার করা যায়।

```javascript
const text = "<b>Hello</b><b>World</b>";

console.log(text.match(/<b>.*?<\/b>/g));
```

Output:

```javascript
["<b>Hello</b>", "<b>World</b>"];
```

### Difference:

```text
.*   → Greedy
.*?  → Lazy
```

# 23.41 `matchAll()`

# 23.50 Password Regex Breakdown

```regex
^
```

→ শুরু

```regex
(?=.*[A-Z])
```

→ অন্তত একটি uppercase

```regex
(?=.*[a-z])
```

→ অন্তত একটি lowercase

```regex
(?=.*\d)
```

→ অন্তত একটি digit

```regex
.{8,}
```

→ অন্তত 8 characters

```regex
$
```

→ শেষ

# 23.76 Regex Security

Regex-এর ক্ষেত্রে একটি advanced security issue আছে:

# ⚠️ ReDoS

**Regular Expression Denial of Service**

কিছু poorly designed regex খুব complex input-এর ক্ষেত্রে অত্যন্ত slow হয়ে যেতে পারে।

বিশেষ করে nested quantifier-এর মতো dangerous pattern:

```regex
(a+)+
```

এর মতো pattern carefully ব্যবহার করতে হয়।

### Best Practice

- Unnecessary complex regex avoid করো
- User-controlled huge input limit করো
- Nested quantifier সাবধানে ব্যবহার করো
- Performance-sensitive regex test করো

# 23.78 Real-Life Project — Registration Validator

```javascript
const usernameRegex = /^[A-Za-z0-9_]{3,16}$/;

const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

const phoneRegex = /^01[3-9]\d{8}$/;

const passwordRegex = /^(?=.*[A-Z])(?=.*[a-z])(?=.*\d)(?=.*[^A-Za-z0-9]).{8,}$/;

function validateUser(user) {
  if (!usernameRegex.test(user.username)) {
    return "Invalid username";
  }

  if (!emailRegex.test(user.email)) {
    return "Invalid email";
  }

  if (!phoneRegex.test(user.phone)) {
    return "Invalid phone";
  }

  if (!passwordRegex.test(user.password)) {
    return "Weak password";
  }

  return "Registration data is valid";
}

const user = {
  username: "Shariar_01",

  email: "shariar@example.com",

  phone: "01712345678",

  password: "Hello@123",
};

console.log(validateUser(user));
```

### Output

```text
Registration data is valid
```

# 23.80 Regex Pattern পড়ার কৌশল

যখন একটি বড় Regex দেখবে, পুরোটা একসাথে বোঝার চেষ্টা করবে না।

ধরো:

```regex
^(?=.*[A-Z])(?=.*[a-z])(?=.*\d)(?=.*[^A-Za-z0-9]).{8,}$
```

এটাকে ভাঙো:

```text
^
↓
start

(?=.*[A-Z])
↓
uppercase আছে?

(?=.*[a-z])
↓
lowercase আছে?

(?=.*\d)
↓
digit আছে?

(?=.*[^A-Za-z0-9])
↓
special character আছে?

.{8,}
↓
minimum 8 characters

$
↓
end
```

এভাবেই Regex পড়তে হয়।
