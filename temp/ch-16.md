# 📘 JavaScript Complete Book — Chapter 16

# Events & Event Handling — Events এবং User Interaction

এখন আমরা JavaScript-এর সবচেয়ে গুরুত্বপূর্ণ practical বিষয়গুলোর একটি শিখব — **Events**।

DOM Chapter-এ আমরা শিখেছি কীভাবে HTML element select করে পরিবর্তন করতে হয়।

কিন্তু একটি webpage-এ user যখন:

* Button click করে
* Input-এ লিখে
* Mouse move করে
* Keyboard press করে
* Form submit করে
* Checkbox select করে
* Page load করে

তখন JavaScript কীভাবে বুঝবে যে **কিছু একটা ঘটেছে**?

এর উত্তর হলো 👉 **Event**।

---

# 16.1 Event কী?

**Event** হলো webpage-এ ঘটে যাওয়া কোনো action বা ঘটনা।

সহজভাবে:

> User বা browser-এর কোনো action ঘটলে সেটাকে Event বলা হয়।

### Real-Life Example

ধরো একটি door:

```text
Door
 ↓
Someone knocks
 ↓
You hear it
 ↓
You open the door
```

Webpage:

```text
Button
 ↓
User clicks
 ↓
Browser detects event
 ↓
JavaScript runs code
```

---

# 16.2 Common Events

JavaScript-এ অনেক ধরনের event আছে।

| Event        | Meaning                     |
| ------------ | --------------------------- |
| `click`      | Mouse click                 |
| `dblclick`   | Double click                |
| `mousedown`  | Mouse button press          |
| `mouseup`    | Mouse button release        |
| `mousemove`  | Mouse move                  |
| `mouseenter` | Element-এর ভিতরে mouse ঢোকে |
| `mouseleave` | Element থেকে mouse বের হয়   |
| `keydown`    | Keyboard key press          |
| `keyup`      | Keyboard key release        |
| `input`      | Input value change          |
| `change`     | Form value change/commit    |
| `submit`     | Form submit                 |
| `focus`      | Element focus পায়           |
| `blur`       | Element focus হারায়         |
| `load`       | Resource/page load          |
| `scroll`     | Page scroll                 |
| `resize`     | Window resize               |

# 16.3 Event Handler কী?

Event ঘটলে যে function execute হয় তাকে সাধারণভাবে **Event Handler** বলা হয়।

Example:

```javascript id="p2oqru"
function handleClick() {
    console.log("Button clicked!");
}
```

এই function-কে click event-এর সাথে connect করলে এটি event handler হিসেবে কাজ করবে।

---

```html id="w3y3oc"

```

JavaScript:

```javascript id="y9tq0n"

button.addEventListener("click", function () {
    console.log("Button clicked!");

```


# 16.5 `addEventListener()`

এটি JavaScript-এ event handle করার সবচেয়ে গুরুত্বপূর্ণ method।

Syntax:

```javascript id="0thx4u"
element.addEventListener("event", function () {
    // code
});
```

Example:

```javascript id="d4lj27"
button.addEventListener("click", function () {
    console.log("Hello");
});
```

এখানে:

```text id="pj6p3g"
button
   ↓
addEventListener()
   ↓
"click"
   ↓
function()
```

# 16.6 Named Function ব্যবহার

Anonymous function-এর পরিবর্তে named function-ও ব্যবহার করা যায়।

```javascript id="2g3hby"
function handleClick() {
    console.log("Clicked!");
}

button.addEventListener("click", handleClick);
```

### খুব গুরুত্বপূর্ণ

সঠিক:

```javascript id="g7f7xm"
button.addEventListener("click", handleClick);
```

ভুল:

```javascript id="u8y9p3"
button.addEventListener("click", handleClick());
```

কারণ `handleClick()` দিলে function তখনই execute হয়ে যাবে।

# 16.10 Event Listener Remove

একটি listener remove করতে একই function reference দরকার।

```javascript id="l8g1vz"
function handleClick() {
    console.log("Clicked");
}

button.addEventListener("click", handleClick);

button.removeEventListener("click", handleClick);
```

এখন click করলে function আর execute হবে না।

### Important

এটি কাজ করবে না:

```javascript id="1p2j3q"
button.addEventListener("click", function () {
    console.log("Clicked");
});

button.removeEventListener("click", function () {
    console.log("Clicked");
});
```

কারণ দুইটি anonymous function আলাদা function object।

# 16.35 `preventDefault()`

# 16.43 Event Bubbling

এটি Chapter 16-এর সবচেয়ে গুরুত্বপূর্ণ advanced concept-এর একটি।

HTML:

```html id="7mx7dy"
<div id="parent">

    <button id="child">
        Click
    </button>

</div>
```

JavaScript:

```javascript id="b5n6v2"
let parent = document.getElementById("parent");
let child = document.getElementById("child");

child.addEventListener("click", function () {
    console.log("Child");
});

parent.addEventListener("click", function () {
    console.log("Parent");
});
```

Button click করলে:

```text id="0q1r4s"
Child
Parent
```

কেন?

কারণ event child থেকে parent-এর দিকে **bubble** করে।

# 16.46 `stopPropagation()`

# 16.50 Event Delegation

এটি খুব গুরুত্বপূর্ণ professional technique।

ধরো:

```html id="h0u7u8"
<ul id="list">

    <li>Apple</li>
    <li>Banana</li>
    <li>Mango</li>

</ul>
```

প্রতিটি `<li>`-তে আলাদা listener না দিয়ে parent-এ listener দিতে পারো।

```javascript id="g1q2x8"
let list = document.getElementById("list");

list.addEventListener("click", function (event) {

    if (event.target.matches("li")) {
        console.log(event.target.textContent);
    }

});
```

```text id="y7j4p0"

```

Mango click:

```text id="5t6n8c"

```

# 16.51 Event Delegation কেন দরকার?

ধরো 1000টি button আছে।

খারাপ approach:

```text id="6c3q9x"
Button 1 → listener
Button 2 → listener
Button 3 → listener
...
Button 1000 → listener
```

Delegation:

```text id="q8p3a1"
Parent
 ↓
একটি listener
 ↓
Target identify
```

এতে code cleaner এবং অনেক ক্ষেত্রে resource usage কমে।

# 16.53 `preventDefault()` বনাম `stopPropagation()`

দুটো একদম আলাদা।

| Method              | কাজ                            |
| ------------------- | ------------------------------ |
| `preventDefault()`  | Browser-এর default action বন্ধ |
| `stopPropagation()` | Event propagation বন্ধ         |

Example:

```javascript id="w5x2qm"
event.preventDefault();
```

→ form submit/navigation-এর default behavior বন্ধ করতে পারে।

```javascript id="9k3m7a"
event.stopPropagation();
```

# 16.60 Real-Life Example — Live Search

HTML:

```html id="7m4p1n"
<input id="search" placeholder="Search...">

<ul id="results"></ul>
```

JavaScript:

```javascript id="4k8z2p"
let search = document.getElementById("search");
let results = document.getElementById("results");

let products = [
    "Laptop",
    "Mouse",
    "Keyboard",
    "Monitor"
];

search.addEventListener("input", function () {

    let keyword = search.value.toLowerCase();

    results.innerHTML = "";

    let filtered = products.filter(function (product) {
        return product.toLowerCase().includes(keyword);
    });

    filtered.forEach(function (product) {

        let li = document.createElement("li");

        li.textContent = product;

        results.append(li);

    });

});
```

```text id="x9m2g5"

   ↓

   ↓

   ↓

   ↓
```

# 16.63 Event Handler-এর ভিতরে `this`

Regular function ব্যবহার করলে event listener-এর ক্ষেত্রে `this` সাধারণত যে element-এ listener attached হয়েছে সেটিকে refer করতে পারে।

```text id="q2p9m6"

```

