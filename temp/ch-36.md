# 📘 Chapter 36 — Modern ECMAScript / ES2020+ Features

JavaScript-এর evolution বুঝতে হলে **ECMAScript** বুঝতে হবে। ES2020 থেকে JavaScript-এ অনেক powerful feature এসেছে, যেগুলো modern React, Node.js এবং Full Stack Development-এ নিয়মিত ব্যবহার হয়।

এই chapter-এ আমরা **ES2020 → ES2021 → ES2022 → ES2023 → ES2024 → ES2025 পর্যন্ত গুরুত্বপূর্ণ modern features** দেখব।

> ⚠️ সব নতুন ECMAScript proposal production feature হয় না। তাই এখানে standardized/modern features-এর ওপর focus করছি।

---

# 36.1 — ECMAScript কী?

**ECMAScript** হলো JavaScript language-এর standard/specification।

সহজভাবে:

```text
ECMAScript
    ↓
JavaScript language-এর specification
    ↓
Browser / Node.js
    ↓
JavaScript চালায়
```

তাই:

```text
JavaScript ≠ ECMAScript
```

আরও সহজভাবে:

> ECMAScript হলো rulebook, আর JavaScript সেই specification-এর একটি বাস্তব implementation।

---

# 36.2 — ES Version কী?

JavaScript সময়ের সাথে নতুন feature পেয়েছে।

যেমন:

```text
ES2015 → let, const, arrow function, class
ES2016 → Array.includes()
ES2017 → async/await
ES2018 → object rest/spread
ES2019 → flat(), flatMap()
ES2020 → ??, ?., BigInt, Promise.allSettled()
ES2021 → ??=, ||=, &&=, replaceAll()
ES2022 → class fields, #private, top-level await
ES2023 → findLast(), toSorted(), toReversed(), toSpliced()
ES2024 → Promise.withResolvers(), Object.groupBy(), Map.groupBy()
ES2025 → নতুন standardized features
```

# 36.3 — কেন Modern JavaScript Features শেখা দরকার?

পুরোনো style:

```javascript
if (user && user.address && user.address.city) {
    console.log(user.address.city);
}
```

Modern JavaScript:

```javascript
console.log(user?.address?.city);
```

পুরোনো style:

```javascript
const name = user.name || "Guest";
```

Modern:

```javascript
const name = user.name ?? "Guest";
```

Modern syntax:

* code ছোট করে
* readability বাড়ায়
* bugs কমাতে সাহায্য করে
* React/Node code cleaner করে
* modern libraries বুঝতে সাহায্য করে

# 36.8 — `||` vs `??`

এটা খুব গুরুত্বপূর্ণ।

```javascript
const value = 0 || 100;

console.log(value);
```

Output:

```text
100
```

কারণ `0` হলো falsy।

কিন্তু:

```javascript
const value = 0 ?? 100;

console.log(value);
```

Output:

```text
0
```

কারণ `??` শুধু:

```text
null
undefined
```

কে missing হিসেবে ধরে।

---

## Comparison

| Value | `value || 100` | `value ?? 100` |
|---|---:|---:|
| `null` | 100 | 100 |
| `undefined` | 100 | 100 |
| `0` | 100 | 0 |
| `false` | 100 | false |
| `""` | 100 | `""` |

# 36.13 — `Promise.allSettled()`

আগে:

```javascript
Promise.all()
```

একটি Promise reject করলে পুরো `Promise.all()` reject করে।

কিন্তু:

```javascript
Promise.allSettled()
```

সব Promise-এর result জানায়।

Example:

```javascript
const promises = [
    Promise.resolve("Success"),
    Promise.reject("Failed"),
    Promise.resolve("Success 2")
];

Promise.allSettled(promises)
    .then(results => console.log(results));
```

Result conceptually:

```javascript
[
    { status: "fulfilled", value: "Success" },
    { status: "rejected", reason: "Failed" },
    { status: "fulfilled", value: "Success 2" }
]
```

### Real-Life Example

তুমি ৩টি API call করলে:

```text
API 1 → Success
API 2 → Failed
API 3 → Success
```

তবুও তুমি তিনটির result-ই জানতে চাও।

তখন:

```javascript
Promise.allSettled()
```

খুব useful।

# 36.32 — `toSorted()`

পুরোনো:

```javascript
const numbers = [3, 1, 2];

numbers.sort();

console.log(numbers);
```

`sort()` original array পরিবর্তন করে।

Modern:

```javascript

```

```text
[1, 2, 3]
[3, 1, 2]
```

Original array unchanged।

# 36.52 — Transpilation vs Polyfill

খুব গুরুত্বপূর্ণ distinction।

### Transpilation

Syntax পরিবর্তন করে।

উদাহরণ conceptually:

```text
Modern JS
   ↓
Compiler
   ↓
Older-compatible JS
```

### Polyfill

যে API নেই, তার implementation provide করে।

যেমন:

```text
Missing API
    ↓
Polyfill
    ↓
Available behavior
```

# 36.57 — Modern JavaScript Interview Questions

### Q1. `||` এবং `??`-এর difference কী?

```javascript
0 || 10
```

→ `10`

```javascript
0 ?? 10
```

→ `0`

কারণ `??` শুধু `null` এবং `undefined` handle করে।

---

### Q2. `sort()` এবং `toSorted()` difference?

```javascript
sort()
```

→ original array mutate করে।

```javascript
toSorted()
```

→ নতুন sorted array দেয়।

---

### Q3. `Promise.all()` এবং `Promise.allSettled()`?

`Promise.all()`:

```text
একটি reject
→ পুরো Promise reject
```

`Promise.allSettled()`:

```text
সবগুলোর final result
→ fulfilled/rejected দুটোই
```

---

### Q4. `Promise.any()` কী করে?

প্রথম fulfilled Promise-এর result দেয়।

সব reject হলে `AggregateError` দেয়।

---

### Q5. Optional chaining কেন ব্যবহার করি?

Nested property missing হলেও error avoid করতে:

```javascript
user?.profile?.name
```

---

### Q6. Private class field কী?

```javascript
class User {
    #password;
}
```

`#password` class-এর বাইরে directly access করা যায় না।

---

### Q7. `.at(-1)` কী করে?

Array/String-এর শেষ element দেয়।

```javascript
[10, 20, 30].at(-1)
```

→ `30`

# 🧠 Quick Cheat Sheet

```javascript
// Optional Chaining
user?.profile?.name;

// Nullish Coalescing
value ?? defaultValue;

// Nullish assignment
value ??= defaultValue;

// OR assignment
value ||= defaultValue;

// AND assignment
value &&= value;

// Replace all
text.replaceAll("old", "new");

// First fulfilled Promise
Promise.any(promises);

// All settled results
Promise.allSettled(promises);

// Last array item
array.at(-1);

// Own property
Object.hasOwn(obj, "key");

// Immutable sort
array.toSorted();

// Immutable reverse
array.toReversed();

// Immutable splice
array.toSpliced();

// Immutable update
array.with(index, value);

// Last matching element
array.findLast(fn);

// Group objects
Object.groupBy(items, fn);

// Private class field
class User {
    #password;
}
```
