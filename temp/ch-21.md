# 📘 Chapter 21 — Asynchronous JavaScript

### **Asynchronous JavaScript — ধীরে/পরে সম্পন্ন হওয়া কাজ কীভাবে JavaScript handle করে**

এখন পর্যন্ত আমরা JavaScript-এর বেশিরভাগ **Synchronous** concept দেখেছি। কিন্তু real-world web application-এ অনেক কাজ আছে যেগুলোর result সঙ্গে সঙ্গে পাওয়া যায় না।

যেমন:

* 🌐 Server থেকে data আনা
* 📡 API call করা
* ⏱️ Timer চালানো
* 📁 File পড়া
* 🗄️ Database-এর সাথে যোগাযোগ
* 👤 Login request
* 📦 Product data load করা

এসবের জন্য JavaScript-এর **Asynchronous Programming** জানা খুবই গুরুত্বপূর্ণ।

---

# 21.1 Synchronous vs Asynchronous

## 🔹 Synchronous JavaScript

Synchronous মানে:

> **একটি কাজ শেষ হওয়ার পর পরের কাজ শুরু হবে।**

### Example

```javascript
console.log("Task 1");
console.log("Task 2");
console.log("Task 3");
```

### Output

```text
Task 1
Task 2
Task 3
```

এখানে JavaScript:

```text
Task 1 → শেষ
       ↓
Task 2 → শেষ
       ↓
Task 3 → শেষ
```

---

## 🔹 Real-Life Example

ধরো তুমি restaurant-এ গেলে।

একজন waiter:

1. Customer 1-এর order নিল
2. Customer 1-এর খাবার তৈরি হওয়া পর্যন্ত দাঁড়িয়ে থাকল
3. খাবার দিল
4. তারপর Customer 2-এর order নিল

এটা inefficient।

এটাই synchronous-এর মতো।

# 21.2 Asynchronous JavaScript

Asynchronous মানে:

> একটি কাজের জন্য অপেক্ষা করতে গিয়ে JavaScript পুরো program-কে আটকে রাখে না।

### Example

```javascript
console.log("Start");

setTimeout(() => {
    console.log("Data received");
}, 2000);

console.log("End");
```

### Output

```text
Start
End
Data received
```

এখানে কী হলো?

```text
Start
  ↓
setTimeout শুরু
  ↓
JavaScript অপেক্ষা না করে
  ↓
End
  ↓
2 seconds পরে
  ↓
Data received
```

# 21.5 JavaScript কেন Async হতে পারে?

JavaScript-এর মূল execution model হলো **single-threaded**।

অর্থাৎ সাধারণভাবে একটি JavaScript execution thread এক সময়ে একটি কাজ execute করে।

কিন্তু Browser environment বিভিন্ন কাজ JavaScript-এর বাইরে handle করতে পারে।

যেমন:

```text
JavaScript
   ↓
Web API
   ↓
Timer / Network / DOM
   ↓
Task Queue
   ↓
Event Loop
   ↓
JavaScript
```

এই mechanism-টাই asynchronous JavaScript বোঝার জন্য খুব গুরুত্বপূর্ণ।

# 21.6 Call Stack

**Call Stack** হলো JavaScript-এর execution-এর জায়গা।

Example:

```javascript
function one() {
    console.log("One");
}

function two() {
    one();
    console.log("Two");
}

two();
```

Execution:

```text
two()
 ↓
one()
 ↓
console.log()
```

Call Stack ধারণাগতভাবে:

```text
┌───────────────┐
│ console.log   │
├───────────────┤
│ one()         │
├───────────────┤
│ two()         │
└───────────────┘
```

যে function আগে আসে, তার execution complete হয়ে stack থেকে বের হয়।

```text
            Call Stack
                 │
                 ▼
        ┌────────────────┐

                 │
                 ▼
              Queue
                 │
                 ▼
            Event Loop
                 │
          Stack empty?
                 │
                 ▼
            Call Stack
```

# 21.12 Promise-এর 3টি State

একটি Promise-এর প্রধান ৩টি state:

| State       | Meaning          |
| ----------- | ---------------- |
| `pending`   | কাজ চলছে         |
| `fulfilled` | কাজ সফল হয়েছে    |
| `rejected`  | কাজ ব্যর্থ হয়েছে |

Diagram:

```text
             Promise
                │
             Pending
             /     \
            /       \
           ▼         ▼
      Fulfilled   Rejected
```

# 21.32 `async/await` কেন এত জনপ্রিয়?

# 21.37 Parallel Async Operations

যদি কাজগুলো একে অপরের উপর depend না করে:

```javascript
async function loadDashboard() {

    const [users, products, orders] = await Promise.all([
        getUsers(),
        getProducts(),
        getOrders()
    ]);

    console.log(users);
    console.log(products);
    console.log(orders);
}
```

এখানে তিনটি operation parallelভাবে শুরু হয়।

### Important

এটা:

```javascript
const users = await getUsers();
const products = await getProducts();
const orders = await getOrders();
```

এর চেয়ে independent operations-এর ক্ষেত্রে বেশি efficient হতে পারে।

# 21.38 `await` Inside Loop

Example:

```javascript
async function process() {

    for (const id of [1, 2, 3]) {

        const data = await getData(id);

        console.log(data);
    }
}
```

এখানে:

```text

↓
2 → complete
↓
3 → complete
```

Sequential execution।

যদি independent হয়, তাহলে অনেক সময়:

```javascript
const results = await Promise.all(
    [1, 2, 3].map(id => getData(id))
);
```

better approach হতে পারে।

# 21.39 Microtask vs Macrotask

এখন একটু advanced concept।

JavaScript asynchronous execution-এ বিভিন্ন queue থাকে।

### সাধারণভাবে:

**Microtask Queue**

* Promise `.then()`
* `.catch()`
* `.finally()`
* `queueMicrotask()`

**Task/Macrotask Queue**

* `setTimeout`
* `setInterval`
* কিছু browser events

# 21.45 HTTP Error সম্পর্কে গুরুত্বপূর্ণ বিষয়

```javascript
}
```

# 21.48 Callback vs Promise vs Async/Await

| Feature        | Callback             | Promise    | Async/Await  |
| -------------- | -------------------- | ---------- | ------------ |
| Readability    | কম                   | ভালো       | ⭐ খুব ভালো   |
| Nested code    | বেশি হতে পারে        | কম         | কম           |
| Error handling | complicated হতে পারে | `.catch()` | `try/catch`  |
| Chaining       | কঠিন                 | `.then()`  | সহজ          |
| Modern JS      | পুরোনো/common        | Standard   | ⭐ খুব common |

> **JavaScript single-threaded হলেও asynchronous programming-এর মাধ্যমে timer, network request, API call ইত্যাদি কাজ handle করতে পারে।**

```javascript
async function getData() {

        return data;

    } catch (error) {
        console.error(error);
    }
}
```

এই pattern তুমি **React + Node.js + Express + REST API + Full Stack Development**-এ বারবার দেখতে পাবে।
