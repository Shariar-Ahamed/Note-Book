# 📘 Chapter 20 — JavaScript Modules

### Modules — বড় JavaScript Project-কে ছোট, Organized ও Reusable File-এ ভাগ করা

এখন পর্যন্ত আমরা JavaScript-এর অনেক core concept শিখেছি। কিন্তু real-world project-এ যদি **একটা মাত্র `.js` file-এর মধ্যে 5,000–10,000 lines code** লিখি, তাহলে project maintain করা কঠিন হয়ে যাবে।

তাই JavaScript-এ code ভাগ করা হয় **Modules**-এ।

---

# 20.1 Module কী?

**Module** হলো JavaScript code-এর একটি আলাদা file, যেখানে নির্দিষ্ট functionality রাখা হয় এবং প্রয়োজন হলে অন্য file-এ `export` / `import` করা যায়।

সহজভাবে:

```text
একটা বড় Project
       ↓
 ┌─────┼─────┐
 ↓     ↓     ↓
auth  cart  utils
.js   .js    .js
```

প্রতিটি file নিজের কাজ করবে।

# 20.16 Named vs Default Export

| বিষয়     | Named Export     | Default Export          |
| -------- | ---------------- | ----------------------- |
| Syntax   | `export { add }` | `export default add`    |
| Import   | `{ add }`        | `add`                   |
| Multiple | Yes              | One default per module  |
| Rename   | `as` দিয়ে        | Import-এই নাম দেওয়া যায় |

Example:

```javascript id="d9x2p6"
// Named
export {
    add,
    subtract
};
```

Import:

```javascript id="e4m7r1"
import {
    add,
    subtract
} from "./math.js";
```

Default:

```javascript id="h8q3w5"
export default add;
```

Import:

```javascript id="k1v6m9"
import add from "./math.js";
```

# 20.21 Module Scope

এটি খুব গুরুত্বপূর্ণ।

Normal script-এ global variable তৈরি হতে পারে।

Module-এ:

```javascript id="k8q2m6"

```

এই variable automatically global scope-এ চলে যায় না।

অন্য module সরাসরি:

```javascript id="s4p9x1"

```

করতে পারবে না।

যদি দরকার হয়:

```javascript id="r7m3v8"

```

তারপর:

```javascript id="n2q6w5"

    username
} from "./user.js";
```

# 20.37 Practical `storage.js`

```javascript id="v5n2k8"
export function saveData(key, value) {

    localStorage.setItem(
        key,
        JSON.stringify(value)
    );

}

export function getData(key) {

    const data =
        localStorage.getItem(key);

    return data
        ? JSON.parse(data)
        : null;
}

export function removeData(key) {

    localStorage.removeItem(key);

}
```

# 20.44 Module vs Normal Script

| বিষয়                       | Normal Script                   | ES Module         |
| -------------------------- | ------------------------------- | ----------------- |
| `import/export`            | ❌                               | ✅                 |
| Scope                      | Global/script scope             | Module scope      |
| Strict semantics           | Not automatically module strict | ✅                 |
| Reusable dependency system | Limited                         | ✅                 |
| `type="module"`            | ❌                               | Browser-এ প্রয়োজন |
| Top-level `await`          | ❌                               | ✅                 |
| Dynamic `import()`         | Modern JS-এ available           | ✅                 |

# 20.46 Node.js-এ Modules

Node.js-এ module system-এর দুটি গুরুত্বপূর্ণ style আছে:

```text id="m4x8p2"
CommonJS
ES Modules
```

CommonJS:

```javascript id="q9v3k7"
const math =
    require("./math");
```

Export:

```javascript id="t6m1r4"
module.exports = {
    add
};
```

Modern Node.js-এ ES Modules-ও ব্যবহার করা যায়:

```javascript id="z2w8n5"
import { add }
from "./math.js";
```

এবং:

```javascript id="p5q7m3"
export {
    add
};
```

# 20.47 CommonJS vs ES Modules

| CommonJS                          | ES Modules                           |
| --------------------------------- | ------------------------------------ |
| `require()`                       | `import`                             |
| `module.exports`                  | `export`                             |
| Node.js-এর traditional system     | JavaScript standard module system    |
| Older Node ecosystem-এ খুব common | Modern JS/browser/Node-এ widely used |

Modern full-stack development-এ দুটো system সম্পর্কে জানা useful।

# 20.48 Circular Dependencies

ধরো:

```text id="s8m2q5"
A.js
 ↓
B.js
 ↓
A.js
```

অর্থাৎ:

```javascript id="v4p9x1"
// A.js
import { b } from "./B.js";
```

আর:

```javascript id="k7m3w8"
// B.js
import { a } from "./A.js";
```

একে **circular dependency** বলে।

এটি কখনো কাজ করতে পারে, কিন্তু complex initialization সমস্যা তৈরি করতে পারে।

তাই architecture এমনভাবে design করা ভালো যাতে unnecessary circular dependency না থাকে।

# 20.49 Modules এবং Encapsulation

ধরো:

```javascript id="c5x8n2"
let balance = 1000;

export function deposit(amount) {

    balance += amount;

}

export function getBalance() {

    return balance;

}
```

অন্য file:

```javascript id="q2m7v4"
import {
    deposit,
    getBalance
} from "./bank.js";

deposit(500);

console.log(
    getBalance()
);
```

Output:

```text id="n8p3x6"
1500
```

অন্য module সরাসরি:

```javascript id="a6w1k9"
balance = 999999;
```

করতে পারবে না।

এটাই module-based encapsulation-এর practical ধারণা।

# 20.50 Live Binding Concept

Modules-এর export সাধারণত **live binding**।

Example:

```javascript id="j4q8m2"
// counter.js

export let count = 0;

export function increment() {
    count++;
}
```

অন্য file:

```javascript id="r7m3x9"
import {
    count,
    increment
} from "./counter.js";

console.log(count);

increment();

console.log(count);
```

Output:

```text id="c5v8p2"
0
1
```

Imported binding module-এর current exported value-এর সাথে linked থাকে।

তবে importer সাধারণত imported binding নিজে reassign করতে পারে না।

# 20.51 Module Cache / Reuse

একই module একাধিক জায়গায় import করলে environment সাধারণত module-টিকে বারবার নতুন করে execute না করে module instance reuse করে।

Example:

```text id="m9x2q6"
app.js ──┐
         ├──→ config.js
cart.js ─┘
```

দুই জায়গা থেকে `config.js` import হলেও একই module instance-এর exports share করা হয়।

এটি application architecture-এ গুরুত্বপূর্ণ।

# 🧠 20.53 Quick Cheat Sheet

| কাজ                | Syntax                              |
| ------------------ | ----------------------------------- |
| Named export       | `export { add }`                    |
| Inline export      | `export function add(){}`           |
| Named import       | `import { add } from "./math.js"`   |
| Rename import      | `import { add as sum } ...`         |
| Default export     | `export default add`                |
| Default import     | `import add from "./math.js"`       |
| Namespace import   | `import * as math from "./math.js"` |
| Side-effect import | `import "./analytics.js"`           |
| Dynamic import     | `import("./math.js")`               |
| Re-export          | `export * from "./math.js"`         |
| Browser module     | `<script type="module">`            |
