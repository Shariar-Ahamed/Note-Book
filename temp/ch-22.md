# 22.3 HTTP কী?

**HTTP = HyperText Transfer Protocol**

এটি web-এর communication protocol।

Browser এবং server HTTP-এর মাধ্যমে communicate করতে পারে।

```text
Client
  │
  │ HTTP Request
  ▼
Server
  │
  │ HTTP Response
  ▼
Client
```

* Mobile App
* React App
* Postman

যে system request receive করে এবং response দেয়।

* Django

# 22.25 Complete Fetch Error Handling

async function getUsers() {

# 22.38 Fetch Timeout

Fetch-এর জন্য নিজে timeout implement করা যায় `AbortController` দিয়ে।

```javascript
async function fetchWithTimeout(url, ms) {

    const controller = new AbortController();

    const timer = setTimeout(() => {
        controller.abort();
    }, ms);

    try {

        const response = await fetch(url, {
            signal: controller.signal
        });

        return response;

    } finally {

        clearTimeout(timer);

    }
}
```

ব্যবহার:

```javascript
try {

    const response = await fetchWithTimeout(
        "/api/data",
        5000
    );

    console.log(await response.json());

} catch (error) {

    console.log("Request failed or timed out");
}
```

    const formData = new FormData(form);

    const user = Object.fromEntries(formData);

        method: "POST",

            "Content-Type": "application/json"
        },

        body: JSON.stringify(user)

# 22.56 GET vs POST

| বিষয়              | GET                       | POST                   |
| ----------------- | ------------------------- | ---------------------- |
| Purpose           | Data নেওয়া                | Data তৈরি/submit       |

# 22.61 API Error Handling — Professional Pattern

```javascript
async function apiRequest(url, options = {}) {

    try {

        const response = await fetch(url, options);

        if (!response.ok) {

            throw new Error(
                `Request failed: ${response.status}`
            );

        }

        const contentType =
            response.headers.get("content-type");

        if (contentType?.includes("application/json")) {

            return await response.json();

        }

        return await response.text();

    } catch (error) {

        console.error("API Error:", error);

        throw error;
    }
}
```

ব্যবহার:

```javascript
const users = await apiRequest("/api/users");

console.log(users);
```

এভাবে একটি reusable API utility তৈরি করা যায়।
