# 32.1 Browser API কী?

**Browser API** হলো browser-এর দেওয়া JavaScript interface, যার মাধ্যমে JavaScript browser-এর বিভিন্ন capability ব্যবহার করতে পারে।

যেমন:

```javascript
navigator.geolocation;
```

এর মাধ্যমে location access করা যায়।

```javascript
navigator.clipboard;
```

এর মাধ্যমে clipboard ব্যবহার করা যায়।

```javascript
window.history;
```

এর মাধ্যমে browser history পরিবর্তন করা যায়।

### সহজভাবে

JavaScript নিজে জানে:

```javascript
let x = 10;
console.log(x);
```

কিন্তু browser JavaScript-কে extra ক্ষমতা দেয়:

```javascript
navigator.geolocation;
navigator.clipboard;
window.history;
window.localStorage;
```

# 32.2 Geolocation API

Website থেকে user's geographic location নেওয়ার জন্য Geolocation API ব্যবহার করা হয়।

### Basic Syntax

```javascript
navigator.geolocation.getCurrentPosition(success, error);
```

### Example

```javascript
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log(position.coords.latitude);
    console.log(position.coords.longitude);
  },
  (error) => {
    console.log(error.message);
  },
);
```

### Output

```text
23.8103
90.4125
```

এগুলো latitude এবং longitude।

### Real-life Example

Food delivery website:

```text
Current Location
       ↓
GPS
       ↓
Latitude + Longitude
       ↓
Nearby Restaurants
```

---

## Position-এর গুরুত্বপূর্ণ properties

```javascript
position.coords.latitude;
position.coords.longitude;
position.coords.accuracy;
position.coords.altitude;
position.coords.speed;
```

সবসময় সব property পাওয়া যাবে এমন নয়।

### Better Example

```javascript
function getLocation() {
  navigator.geolocation.getCurrentPosition(
    (position) => {
      const { latitude, longitude } = position.coords;

      console.log(`Latitude: ${latitude}`);
      console.log(`Longitude: ${longitude}`);
    },
    (error) => {
      console.error("Location error:", error.message);
    },
  );
}

getLocation();
```

---

## `watchPosition()`

User-এর location continuously track করার জন্য:

```javascript
const watchId = navigator.geolocation.watchPosition((position) => {
  console.log(position.coords.latitude);
});
```

Stop করতে:

```javascript
navigator.geolocation.clearWatch(watchId);
```

### Real-life

Ride-sharing app:

```text
Driver moves
     ↓
GPS updates
     ↓
watchPosition()
     ↓
Map updates
```

⚠️ Location permission এবং privacy অত্যন্ত গুরুত্বপূর্ণ।

# 32.9 IntersectionObserver

এটি detect করতে পারে কোনো element viewport-এর মধ্যে এসেছে কিনা।

### Basic Example

```javascript
const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      console.log("Element visible!");
    }
  });
});

const box = document.querySelector(".box");

observer.observe(box);
```

---

## Real-life use

### Lazy loading

```text
Page
 ↓
Image এখনো screen-এর বাইরে
 ↓
User scroll করে
 ↓
Image viewport-এ আসে
 ↓
IntersectionObserver
 ↓
Image load
```

---

## Lazy image example

```html
<img class="lazy" data-src="image.jpg" alt="Example" />
```

```javascript
const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      const img = entry.target;

      img.src = img.dataset.src;

      observer.unobserve(img);
    }
  });
});

document.querySelectorAll(".lazy").forEach((img) => observer.observe(img));
```

🔥 Performance optimization-এ খুব important।

# 32.12 IntersectionObserver vs MutationObserver vs ResizeObserver

| API                    | কী observe করে?                              |
| ---------------------- | -------------------------------------------- |
| `IntersectionObserver` | Element viewport-এর সাথে intersect করছে কিনা |
| `MutationObserver`     | DOM change                                   |
| `ResizeObserver`       | Element size change                          |

🧠 সহজে মনে রাখুন:

```text
Intersection → Screen visibility
Mutation     → DOM changes
Resize       → Size changes
```

# 32.19 Web Workers

JavaScript-এর heavy কাজ main thread block করতে পারে।

Web Worker ব্যবহার করলে আলাদা worker context-এ JavaScript চালানো যায়।

### Main file

```javascript
const worker = new Worker("worker.js");

worker.postMessage(1000000000);

worker.onmessage = (event) => {
  console.log(event.data);
};
```

### worker.js

```javascript
self.onmessage = (event) => {
  const number = event.data;

  let result = 0;

  for (let i = 0; i < number; i++) {
    result += i;
  }

  self.postMessage(result);
};
```

### Communication

```text
Main Thread
    ↓ postMessage()
Worker
    ↓ postMessage()
Main Thread
```

---

## কেন Worker?

ধরুন:

```javascript
for (let i = 0; i < 10_000_000_000; i++) {
  // heavy work
}
```

Main thread-এ করলে UI freeze করতে পারে।

Worker ব্যবহার করলে main UI responsive রাখা যায়।

### Real-life

- image processing
- large calculations
- data processing
- encryption-related computation
- parsing large datasets

⚠️ Worker-এর DOM access সরাসরি করা যায় না।

# 32.31 Practical Project — Image Preview

HTML:

```html
<input type="file" id="imageInput" />

<img id="preview" width="300" alt="Preview" />
```

JavaScript:

```javascript
const input = document.querySelector("#imageInput");

const preview = document.querySelector("#preview");

input.addEventListener("change", () => {
  const file = input.files[0];

  if (!file) return;

  const url = URL.createObjectURL(file);

  preview.src = url;

  preview.onload = () => {
    URL.revokeObjectURL(url);
  };
});
```

### এখানে কী শিখলাম?

```text
<input type=file>
       ↓
File
       ↓
Object URL
       ↓
Image Preview
       ↓
revokeObjectURL()
```

# 32.32 Practical Project — Copy Button

HTML:

```html
<p id="text">JavaScript is powerful.</p>

<button id="copyBtn">Copy</button>
```

JavaScript:

```javascript
const text = document.querySelector("#text");

const button = document.querySelector("#copyBtn");

button.addEventListener("click", async () => {
  try {
    await navigator.clipboard.writeText(text.textContent);

    button.textContent = "Copied!";

    setTimeout(() => {
      button.textContent = "Copy";
    }, 1500);
  } catch (error) {
    console.error(error);
  }
});
```

# 32.33 Practical Project — Lazy Loading

```html
<img class="lazy" data-src="large-image.jpg" width="500" alt="Large image" />
```

```javascript
const images = document.querySelectorAll(".lazy");

const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (!entry.isIntersecting) return;

    const img = entry.target;

    img.src = img.dataset.src;

    observer.unobserve(img);
  });
});

images.forEach((img) => {
  observer.observe(img);
});
```

এটি large website-এর performance improve করতে সাহায্য করতে পারে।
