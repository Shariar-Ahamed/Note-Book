# 38.1 React-এর জন্য Advanced JavaScript কেন?

React মূলত JavaScript-এর উপর তৈরি।

তাই React-এ এই ধরনের code খুব common:

```javascript
const users = [
  { name: "Ripon", age: 23 },
  { name: "Rahim", age: 22 }
];

const names = users.map(user => user.name);
```

এখানে React নেই, কিন্তু React application-এ এই ধরনের JavaScript প্রতিদিন ব্যবহার করতে হবে।

### সহজভাবে:

```text
JavaScript
   ↓
Modern JavaScript
   ↓
React
   ↓
Next.js / Full Stack
```

তাই Advanced JavaScript ভালোভাবে জানা = React অনেক সহজ হয়ে যাওয়া।

# 38.2 Destructuring

Destructuring হলো object বা array থেকে প্রয়োজনীয় value সরাসরি variable-এ বের করে নেওয়া।

## Object Destructuring

```javascript
const user = {
  name: "Ripon",
  age: 23,
  city: "Dhaka"
};

const { name, age } = user;

console.log(name);
console.log(age);
```

### Output

```text
Ripon
23
```

আগে লিখতে হতো:

```javascript
const name = user.name;
const age = user.age;
```

Destructuring:

```javascript
const { name, age } = user;
```

### React Example

```jsx
function UserCard({ name, age }) {
  return (
    <div>
      <h2>{name}</h2>
      <p>{age}</p>
    </div>
  );
}
```

এখানে:

```javascript
{name, age}
```

হলো props destructuring।

# 38.3 Array Destructuring

```javascript
const colors = ["red", "green", "blue"];

const [first, second, third] = colors;

console.log(first);
console.log(second);
console.log(third);
```

Output:

```text
red
green
blue
```

React-এর সবচেয়ে famous example:

```javascript
const [count, setCount] = useState(0);
```

এখানে:

```text
count     → প্রথম value
setCount  → দ্বিতীয় value
```

অর্থাৎ React-এর `useState()` বুঝতেও Array Destructuring জানা দরকার।

# 38.4 Spread Operator `...`

Spread operator একটি array/object-এর elements বা properties ছড়িয়ে দেয়।

## Array

```javascript
const numbers = [1, 2, 3];

const newNumbers = [...numbers, 4, 5];

console.log(newNumbers);
```

Output:

```text
[1, 2, 3, 4, 5]
```

---

## Object

```javascript
const user = {
  name: "Ripon",
  age: 23
};

const updatedUser = {
  ...user,
  age: 24
};

console.log(updatedUser);
```

Output:

```text

  name: "Ripon",
  age: 24
}
```

### React-এ অত্যন্ত গুরুত্বপূর্ণ

```javascript
setUser({
  ...user,
  age: 24

```

এর অর্থ:

> আগের user-এর সব property রাখো, শুধু `age` পরিবর্তন করো।


# 38.8 `find()`

প্রথম matching element return করে।

```javascript
const users = [
  { id: 1, name: "Ripon" },
  { id: 2, name: "Rahim" }
];

const user = users.find(user => user.id === 2);

console.log(user);
```

Output:

```text
{ id: 2, name: "Rahim" }
```

### `filter()` বনাম `find()`

| Method     | Result                 |
| ---------- | ---------------------- |
| `find()`   | প্রথম matching element |
| `filter()` | সব matching element    |

# 38.13 Immutability

React-এর সবচেয়ে গুরুত্বপূর্ণ conceptগুলোর একটি।

**Immutability = existing data সরাসরি পরিবর্তন না করা।**

❌ Bad:

```javascript
user.name = "Rahim";
```

Better:

```javascript
setUser({
  ...user,
  name: "Rahim"
});
```

# 38.14 কেন React-এ Immutability গুরুত্বপূর্ণ?

React state update detect করতে reference comparison ব্যবহার করে।

ধরো:

```javascript

  name: "Ripon"
};
```

সরাসরি:


করলে একই object reference থাকে।


এখানে নতুন object তৈরি হয়।

```text
Old Object
     ↓
   copy
     ↓

```

React state management-এর জন্য এই pattern অত্যন্ত গুরুত্বপূর্ণ।


```javascript

const user2 = user1;

user2.name = "Rahim";

console.log(user1.name);
```

Output:


# 38.19 Shallow Copy

```javascript
const user = {
  name: "Ripon",
  age: 23
};

const copy = {
  ...user
};
```

এখন:

```text
user !== copy
```

কিন্তু nested object থাকলে সমস্যা হতে পারে।

```javascript
const user = {
  name: "Ripon",
  address: {
    city: "Dhaka"
  }
};

const copy = { ...user };

copy.address.city = "Dinajpur";
```

এতে original-এর nested object-ও পরিবর্তিত হতে পারে।

কারণ spread **deep copy নয়**।

# 38.26 Higher-Order Function

যে function:

* অন্য function গ্রহণ করে অথবা
* function return করে

```javascript

);

```

Output:

```text
30
```

React-এর:

```javascript
map()
filter()
reduce()
```

# 38.28 Closures in React

Closure মানে inner function তার outer scope-এর variable মনে রাখতে পারে।

```javascript
function counter() {
  let count = 0;

  return function () {
    count++;
    return count;
  };
}

const increase = counter();

console.log(increase());
console.log(increase());
```

Output:

```text
1
2
```

React-এ event handler এবং hooks-এর behaviour বুঝতে closure অত্যন্ত গুরুত্বপূর্ণ।

# 38.31 Pure Function

Pure function:

1. একই input → একই output

```javascript
let total = 0;

function addToTotal(value) {
```

# 38.32 `this` in React

Modern React functional components-এ সাধারণত class-এর মতো `this` লাগে না।

পুরনো React:

```javascript
class Counter extends React.Component {
  handleClick() {
    this.setState({
      count: this.state.count + 1
    });
  }
}
```

Modern React:

```jsx
function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}
```

তাই modern React শেখার জন্য `this` জানা দরকার হলেও এর ব্যবহার অনেক কম।

# 38.43 Debounce

User typing:

```text
R
Ri
Rip
Ripo
Ripon
```

প্রতিবার API call করলে unnecessary request হবে।

Debounce:

> User typing বন্ধ করার কিছু সময় পর function চালাও।

```javascript
function debounce(callback, delay) {
  let timer;

  return (...args) => {
    clearTimeout(timer);

    timer = setTimeout(() => {
      callback(...args);
    }, delay);
  };
}
```

Search:

```javascript
const search = debounce(value => {
  console.log("API call:", value);
}, 500);
```

# 38.45 React State Update

ধরো:

```jsx

```

Wrong ধারণা:

```javascript

```

```javascript
setCount(count + 1);
```

আর previous state-এর উপর নির্ভর করলে:

```javascript
setCount(prevCount => prevCount + 1);
```

### কেন?

কারণ React state update asynchronous/batched হতে পারে।

এই pattern safer:

```javascript
setCount(prev => prev + 1);
```

# 38.49 Common Mistake — `map()` এ `return` ভুলে যাওয়া

❌:

```javascript

users.map(user => (
```

```javascript
users.map(user => {
```

# 38.52 Common Mistake — Index কে সবসময় `key` হিসেবে ব্যবহার করা

```jsx
{items.map((item, index) => (
  <div key={index}>
    {item.name}
  </div>

```

Static list হলে কখনো acceptable হতে পারে।

কিন্তু list যদি:

* reorder হয়
* delete হয়
* insert হয়

তাহলে stable unique ID ব্যবহার করা better:

```jsx
key={item.id}
```

# 🧠 Quick Cheat Sheet

```javascript
// Destructuring
const { name } = user;

// Array destructuring
const [first, second] = items;

// Spread
const newArray = [...oldArray];

// Object spread
const newUser = { ...user, age: 24 };

// Rest
const [first, ...rest] = numbers;

// Map
items.map(item => item.name);

// Filter
items.filter(item => item.active);

// Find
items.find(item => item.id === 1);

// Some
items.some(item => item.active);

// Every
items.every(item => item.active);

// Reduce
items.reduce((sum, item) => sum + item.price, 0);

// Optional chaining
user?.profile?.name;

// Nullish
name ?? "Guest";

// Ternary
isLoggedIn ? <Dashboard /> : <Login />;

// Short circuit
isAdmin && <AdminPanel />;

// Immutable update
setUser(prev => ({
  ...prev,
  name: "Rahim"
}));

// Immutable array add
setItems(prev => [...prev, item]);

// Immutable delete
setItems(prev =>
  prev.filter(item => item.id !== id)
);

// Immutable update
setItems(prev =>
  prev.map(item =>
    item.id === id
      ? { ...item, done: true }
      : item
  )
);
```
