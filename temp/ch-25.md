# 📘 Chapter 25 — Functional JavaScript

### Functional Programming (FP) — Functional JavaScript শেখা

JavaScript-এ **Functional Programming** খুব গুরুত্বপূর্ণ, বিশেষ করে তুমি যখন **React, Node.js, modern JavaScript** নিয়ে কাজ করবে।

এই Chapter-এ আমরা শুধু `map()` / `filter()` না, বরং Functional JavaScript-এর মূল ধারণাগুলো **basic → advanced** ভাবে শিখব।

---

# 25.1 Functional Programming কী?

**Functional Programming (FP)** হলো এমন একটি programming style যেখানে আমরা program-কে ছোট ছোট **function** দিয়ে তৈরি করি এবং function-কে data process করার প্রধান মাধ্যম হিসেবে ব্যবহার করি।

### সহজ ভাষায়

ধরো একটি restaurant-এ:

> Raw ingredients → রান্নার function → Final food

JavaScript-এ:

> Input data → Function → Output data

```javascript
function double(number) {
  return number * 2;
}

console.log(double(5));
```

### Output

```text
10
```

এখানে:

```text
5 → double() → 10
```

অর্থাৎ function input নিয়ে output তৈরি করেছে।

# 25.3 Pure Function

একটি function তখন **Pure Function**, যখন:

1. একই input দিলে সবসময় একই output দেয়
2. বাইরের কোনো data পরিবর্তন করে না

### Example

```javascript
function add(a, b) {
  return a + b;
}

console.log(add(10, 20));
console.log(add(10, 20));
```

### Output

```text
30
30
```

একই input:

```text
10, 20
```

দিলে সবসময়:

```text
30
```

তাই এটি pure function।

---

# 25.4 Impure Function

যে function বাইরের state/data পরিবর্তন করে অথবা বাইরের changing value-এর ওপর নির্ভর করে তাকে সাধারণভাবে **Impure Function** বলা হয়।

```javascript
let total = 0;

function addToTotal(value) {
  total += value;
}

addToTotal(100);

console.log(total);
```

### Output

```text
100
```

Function-এর ভিতর থেকে বাইরের variable:

```javascript
total;
```

পরিবর্তন হয়েছে।

তাই এটি pure function নয়।

---

# 25.5 Pure vs Impure

| Pure Function               | Impure Function                 |
| --------------------------- | ------------------------------- |
| একই input → একই output      | output/state পরিবর্তিত হতে পারে |
| বাইরের data পরিবর্তন করে না | বাইরের data পরিবর্তন করতে পারে  |
| Predictable                 | Less predictable                |
| Testing সহজ                 | Testing তুলনামূলক কঠিন          |

### Pure

```javascript
function square(x) {
  return x * x;
}
```

### Impure

```javascript
let count = 0;

function increase() {
  count++;
}
```

# 25.7 Side Effect কী?

Function-এর বাইরে কোনো observable পরিবর্তন হলে সেটি **Side Effect** হতে পারে।

উদাহরণ:

```javascript
console.log();
```

```javascript
document.body.innerHTML = "Hello";
```

```javascript
localStorage.setItem("name", "Ripon");
```

```javascript
database.save(user);
```

```javascript
fetch("/api/users");
```

এসব operation সাধারণত side effect তৈরি করে।


```javascript

```

# 25.9 Pure Version

আমরা নতুন array return করতে পারি:

```javascript
let users = [];

function addUser(users, user) {
  return [...users, user];
}

const updatedUsers = addUser(users, "Ripon");

console.log(users);
console.log(updatedUsers);
```

### Output

```text
[]
["Ripon"]
```

Original array পরিবর্তন হয়নি।

এটাই Functional Programming-এর গুরুত্বপূর্ণ ধারণা।

# 25.10 Immutability

**Immutability** মানে হলো existing data সরাসরি পরিবর্তন না করা।

ধরো:

```javascript
const user = {
  name: "Ripon",
  age: 23,
};
```

এখন:

```javascript
user.age = 24;
```

এখানে object-এর existing data পরিবর্তন হয়েছে।

Functional style-এ আমরা নতুন object তৈরি করতে পারি।

```javascript
const user = {
  name: "Ripon",
  age: 23,
};

const updatedUser = {
  ...user,
  age: 24,
};

console.log(user);
console.log(updatedUser);
```

### Output

```text
{ name: "Ripon", age: 23 }

{ name: "Ripon", age: 24 }
```

Original object unchanged।

# 25.12 First-Class Functions

- object/property হিসেবে রাখা যায়

# 25.15 Higher-Order Function

যে function:

- অন্য function গ্রহণ করে

অথবা

- অন্য function return করে

তাকে **Higher-Order Function** বলে।

### Example

```javascript
function calculate(a, b, operation) {
  return operation(a, b);
}

function add(a, b) {
  return a + b;
}

console.log(calculate(10, 20, add));
```

### Output

```text
30
```

এখানে:

```javascript
calculate();
```

একটি Higher-Order Function।

# 25.17 `map()`

`map()` প্রতিটি element-এর ওপর function চালিয়ে **নতুন array** তৈরি করে।

```javascript

```

```text
[1, 2, 3, 4]
```

পরিবর্তিত হয়নি।

# 25.21 `reduce()`

`reduce()` multiple valuesকে একটি final value-তে পরিণত করতে পারে।

```javascript
const numbers = [10, 20, 30, 40];

const total = numbers.reduce((sum, number) => sum + number, 0);

console.log(total);
```

### Output

```text
100
```

Mental model:

```text
0
 ↓
0 + 10 = 10
 ↓
10 + 20 = 30
 ↓
30 + 30 = 60
 ↓
60 + 40 = 100
```

# 25.22 `map()` + `filter()` + `reduce()`

Functional JavaScript-এর সবচেয়ে গুরুত্বপূর্ণ patternগুলোর একটি।

```javascript
const prices = [100, 200, 300, 400];

const result = prices
  .filter((price) => price >= 200)
  .map((price) => price * 0.9)
  .reduce((total, price) => total + price, 0);

console.log(result);
```

### Step-by-step

প্রথম:

```text
[100, 200, 300, 400]
```

`filter()`:

```text
[200, 300, 400]
```

`map()`:

```text
[180, 270, 360]
```

`reduce()`:

```text
810
```

### Output

```text
810
```

এটি Functional Programming-এর খুব গুরুত্বপূর্ণ style।

# 25.23 Declarative Programming

Functional Programming সাধারণত **Declarative** style ব্যবহার করে।

### Imperative

মানে কীভাবে কাজ করতে হবে সেটা বলে দেওয়া।

```javascript
const numbers = [1, 2, 3, 4];
const result = [];

for (let i = 0; i < numbers.length; i++) {
  result.push(numbers[i] * 2);
}

console.log(result);
```

### Declarative

কী result চাই সেটা প্রকাশ করা:

```javascript
const numbers = [1, 2, 3, 4];

const result = numbers.map((number) => number * 2);

console.log(result);
```

দুটোর output একই:

```text
[2, 4, 6, 8]
```

---

# 25.24 Imperative vs Declarative

| Imperative      | Declarative            |
| --------------- | ---------------------- |
| কীভাবে করতে হবে | কী চাই                 |
| বেশি control    | বেশি abstraction       |
| loops বেশি      | methods বেশি           |
| step-by-step    | transformation-focused |

# 25.25 Function Composition

একাধিক ছোট function একসাথে ব্যবহার করে বড় কাজ তৈরি করাকে **Function Composition** বলা হয়।

ধরো:

```text
Input
 ↓
double
 ↓
add10
 ↓
square
 ↓
Output
```

Code:

```javascript
const double = (x) => x * 2;

const add10 = (x) => x + 10;

const square = (x) => x * x;

const result = square(add10(double(5)));

console.log(result);
```

### Calculation

```text
double(5)
= 10

add10(10)
= 20

square(20)
= 400
```

### Output

```text
400
```

---

# 25.26 নিজের `compose()` Function

আমরা composition-এর জন্য function তৈরি করতে পারি।

```javascript
const compose = (f, g) => (value) => f(g(value));

const double = (x) => x * 2;
const add10 = (x) => x + 10;

const process = compose(add10, double);

console.log(process(5));
```

### Output

```text
20
```

কারণ:

```text
5
↓
double → 10
↓
add10 → 20
```

---

# 25.27 `pipe()`

`compose()` সাধারণত right-to-left কাজ করতে পারে।

আর `pipe()` সাধারণত left-to-right।

```javascript
const pipe =
  (...functions) =>
  (value) =>
    functions.reduce((result, fn) => fn(result), value);
```

এখন:

```javascript
const double = (x) => x * 2;
const add10 = (x) => x + 10;
const square = (x) => x * x;

const process = pipe(double, add10, square);

console.log(process(5));
```

### Output

```text
400
```

কারণ:

```text
5
↓
double → 10
↓
add10 → 20
↓
square → 400
```

# 25.30 Why React Developers Need This

React state সরাসরি mutate করা উচিত নয়।

খারাপ pattern:

```javascript
user.name = "New Name";
```

Better:

```javascript
setUser({
  ...user,
  name: "New Name",
});
```

Array-এর ক্ষেত্রে:

```javascript
setUsers(
  users.map((user) => (user.id === 2 ? { ...user, active: true } : user)),
);
```

এই কারণেই Functional JavaScript ভালোভাবে জানা React-এর জন্য খুব গুরুত্বপূর্ণ।

# 25.31 Referential Transparency

একটি expression যদি তার result দিয়ে safely replace করা যায় এবং program-এর behavior পরিবর্তন না হয়, তাকে **Referential Transparency** বলা হয়।

ধরো:

```javascript
function add(a, b) {
  return a + b;
}
```

তাহলে:

```javascript
add(10, 20);
```

সবসময়:

```text
30
```

তাই:

```javascript
const x = add(10, 20);
```

কে:

```javascript
const x = 30;
```

দিয়ে replace করা যায়।

# 25.32 Currying

**Currying** হলো একটি function-এর multiple arguments-কে একসাথে নেওয়ার পরিবর্তে একবারে একটি করে নেওয়া।

Normal:

```javascript
function add(a, b) {
  return a + b;
}

console.log(add(10, 20));
```

Curried:

```javascript
function add(a) {
  return function (b) {
    return a + b;
  };
}

console.log(add(10)(20));
```

### Output

```text
30
```

Arrow version:

```javascript
const add = (a) => (b) => a + b;

console.log(add(10)(20));
```

ধরো tax calculation:

```javascript
const addTax = (taxRate) => (price) => price + price * taxRate;

const addVAT = addTax(0.15);

console.log(addVAT(1000));
console.log(addVAT(2000));
```

### Output

```text
1150
2300
```

এখানে:

```javascript
addTax(0.15);
```

একটি reusable function তৈরি করেছে।

# 25.34 Partial Application

Currying-এর সঙ্গে সম্পর্কিত আরেকটি concept হলো **Partial Application**।

ধরো:

```javascript
function multiply(a, b, c) {
  return a * b * c;
}
```

আমরা কিছু argument আগে সেট করতে পারি।

```javascript
function multiplyBy(a) {
  return (b, c) => a * b * c;
}

const multiplyBy2 = multiplyBy(2);

console.log(multiplyBy2(3, 4));
```

### Output

```text
24
```

# 25.35 Closure + Functional Programming

Currying এবং functional programming-এ closure অনেক গুরুত্বপূর্ণ।

```javascript
function createMultiplier(multiplier) {
  return function (number) {
    return number * multiplier;
  };
}

const double = createMultiplier(2);
const triple = createMultiplier(3);

console.log(double(10));
console.log(triple(10));
```

### Output

```text
20
30
```

Inner function `multiplier` variable-টিকে মনে রাখছে।

এটাই closure।

# 25.37 Sorting Without Mutation

একটি গুরুত্বপূর্ণ বিষয়:

```javascript

```

original array mutate করে।

```javascript
const numbers = [3, 1, 2];

```

Original array পরিবর্তিত হয়েছে।

# 25.38 `forEach()` vs `map()`

### `forEach()`

সাধারণত side effect করার জন্য:

```javascript
const numbers = [1, 2, 3];

numbers.forEach((number) => {
  console.log(number);
});
```

### `map()`

নতুন transformed array তৈরি করার জন্য:

```javascript
const doubled = numbers.map((number) => number * 2);
```

### মনে রাখবে


# 25.43 Functional Data Pipeline

এখন একটি realistic example দেখি।

ধরো e-commerce products:

```javascript
const products = [
  { name: "Laptop", price: 80000, stock: 5 },
  { name: "Mouse", price: 1000, stock: 20 },
  { name: "Keyboard", price: 3000, stock: 0 },
  { name: "Monitor", price: 25000, stock: 8 },
];
```

আমরা available এবং 5000-এর বেশি price-এর product চাই।

```javascript
const result = products
  .filter((product) => product.stock > 0)
  .filter((product) => product.price > 5000)
  .map((product) => ({
    ...product,
    price: product.price * 0.9,
  }));

console.log(result);
```

### Output

```text
[
    { name: "Laptop", price: 72000, stock: 5 },
    { name: "Monitor", price: 22500, stock: 8 }
]
```

এখানে:

```text
products
   ↓
filter stock
   ↓
filter price
   ↓
map discount
   ↓
result
```

এটাকে **Data Transformation Pipeline** হিসেবে ভাবতে পারো।

# 25.46 Functional Programming-এর অসুবিধা

সবসময় functional style ব্যবহার করাই সঠিক নয়।

কিছু ক্ষেত্রে:

- বেশি function তৈরি হতে পারে

> **Functional style যেখানে code পরিষ্কার ও predictable হয়, সেখানে ব্যবহার করা।**

# 25.48 Result Calculation with `reduce()`

```javascript
const students = [
  { name: "Rahim", marks: 80 },
  { name: "Karim", marks: 45 },
  { name: "Nadia", marks: 90 },
];

const totalMarks = students.reduce(
  (total, student) => total + student.marks,

);

const average = totalMarks / students.length;

console.log("Average:", average);
```

```text
Average: 71.66666666666667
```

# 🧠 Quick Cheat Sheet

| Concept               | Meaning                               |
| --------------------- | ------------------------------------- |
| Pure Function         | Same input → same output              |
| Impure Function       | External state/side effect থাকতে পারে |
| Side Effect           | Function-এর বাইরে observable change   |
| Immutability          | Existing data সরাসরি পরিবর্তন না করা  |
| First-Class Function  | Function-কে value হিসেবে ব্যবহার করা  |
| Higher-Order Function | Function নেয়/return করে               |
| `map()`               | Data transform                        |
| `filter()`            | Data select                           |
| `reduce()`            | Multiple values → one value           |
| `find()`              | First matching item                   |
| `some()`              | অন্তত একটি match                      |
| `every()`             | সব match                              |
| Composition           | Multiple functions combine            |
| Currying              | Arguments একবারে একটি করে নেওয়া       |
| Declarative           | কী চাই সেটা বলা                       |
