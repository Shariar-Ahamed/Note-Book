# 39.1 Node.js কী?

Node.js হলো এমন একটি runtime environment যার মাধ্যমে browser-এর বাইরে JavaScript চালানো যায়।

আগে JavaScript মূলত:

```text
Browser
   ↓
Chrome / Firefox / Edge
   ↓
JavaScript
```

Node.js-এর মাধ্যমে:

```text
Computer / Server
        ↓
      Node.js
        ↓
   JavaScript
```

চালানো যায়।

# 39.7 Node.js কেন দ্রুত?

Node.js-এর শক্তিশালী দিক হলো **non-blocking I/O**।

ধরো server-কে file read করতে হবে:

```text
Request
  ↓
File Read
  ↓
Waiting...
```

পুরো JavaScript execution block না করে Node অন্য কাজ handle করতে পারে।

```text
Request A
   ↓
File I/O ─────────┐
                  │
Request B ← Node  │
                  │
Request C ← Node  │
                  ↓
             File Result
```

এটি high-concurrency application-এর জন্য useful।

# 39.20 Named CommonJS Export

```javascript

  subtract
```

# 39.21 ES Modules

```javascript

  return a + b;
```

```javascript

```

Node.js-এ ESM ব্যবহার করতে `package.json`-এ:

```json
{
  "type": "module"
```

# 39.22 `require()` বনাম `import`

| CommonJS                      | ES Modules           |
| ----------------------------- | -------------------- |
| `require()`                   | `import`             |
| `module.exports`              | `export`             |
| Node.js-এ traditional         | Modern standard      |
| `__dirname` available         | `import.meta.url`    |
| synchronous loading semantics | static module syntax |

Modern full-stack projects-এ ESM অনেক বেশি দেখা যায়, তবে CommonJS এখনও গুরুত্বপূর্ণ।

# 39.40 Streams

বড় data একবারে memory-তে না এনে **ছোট ছোট chunk** হিসেবে process করার জন্য Streams ব্যবহার করা হয়।

ধরো 5GB video।

❌ পুরো file memory-তে load করা:

```text
5GB
 ↓
RAM
```

সমস্যা হতে পারে।

Stream:

```text
5GB File
   ↓
Chunk
Chunk
Chunk
Chunk
Chunk
   ↓
Output
```

এটি অনেক efficient।

# 39.44 `pipe()`

Readable stream → Writable stream:

```javascript
const readStream =
  fs.createReadStream("input.txt");

  fs.createWriteStream("output.txt");

```

Concept:

```text
input.txt
   ↓
Readable Stream
   ↓
pipe()
   ↓
Writable Stream
   ↓
output.txt
```

# 39.52 HTTP Server

# 39.72 Node.js-এ `Promise.all()`

একসাথে independent কাজ করতে:

```javascript

  getUsers(),
```

```text
getUsers() ─────┐
                ├── Promise.all()
getProducts() ──┘
```

একটি কাজ আরেকটির result-এর উপর নির্ভর না করলে এটি useful।

---

# 39.73 Sequential বনাম Parallel

Sequential:

```javascript
const users = await getUsers();
const products = await getProducts();
```

এখানে দ্বিতীয় কাজ প্রথমটির পরে শুরু হয়।

Parallel:

```javascript
const [users, products] =
  await Promise.all([
    getUsers(),
    getProducts()
  ]);
```

Independent হলে parallel approach latency কমাতে পারে।

# 39.74 `Promise.allSettled()`

যদি সব result দেখতে চাও—even কিছু fail করলেও:

```javascript
const results = await Promise.allSettled([
  getUsers(),
  getProducts(),
  getOrders()
]);
```

এটি প্রতিটি operation-এর:

```text
fulfilled
rejected
```

status দেয়।
