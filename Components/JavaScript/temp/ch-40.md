# 40.7 Clean Code

Clean Code মানে:

> এমন code যা অন্য developer সহজে বুঝতে, maintain করতে এবং modify করতে পারে।

❌ Bad:

```javascript

  return a * b;
}
```

```javascript

  price,
  quantity

  return price * quantity;
}
```

# 40.9 DRY

**DRY = Don't Repeat Yourself**

ধরো:

```javascript
console.log("User logged in");
console.log("User logged in");
console.log("User logged in");
```

এভাবে repeated logic থাকলে function:

```javascript
function logLogin() {
  console.log("User logged in");
}
```

তারপর:

```javascript
logLogin();
logLogin();
logLogin();
```

### তবে একটা গুরুত্বপূর্ণ বিষয়

DRY মানে সব duplicate-looking code জোর করে abstraction করা নয়।

অতিরিক্ত abstraction code আরও complex করতে পারে।

তাই শুধু login-এর জন্য:

সব OAuth একসাথে বানানোর প্রয়োজন নেই যদি requirement না থাকে।

# 40.18 Error Handling Strategy

Production application-এ error তিনভাবে ভাবো:

```text
Expected Error
Unexpected Error
Operational Error
```

Example:

```text
404 → User not found
401 → Authentication required
403 → Permission denied
500 → Unexpected server error
```

User-কে unnecessary internal details দেখাবে না।

❌:

```json
{
  "error": "Database connection failed at /var/app/src/db/index.js line 52..."
}
```

Better:

```json
{
  "message": "Internal server error"
}
```

Server log-এ বিস্তারিত থাকবে।

# 40.19 Frontend Error Handling

# 40.39 JavaScript Interview — Basic Questions

## Q1. `var`, `let`, `const` পার্থক্য কী?

সংক্ষেপে:

```text
var   → function scoped
let   → block scoped
const → block scoped + reassignment করা যায় না
```

## Q2. `==` বনাম `===`

```javascript
5 == "5"   // true
5 === "5"  // false
```

Modern code-এ সাধারণত `===` preferred।

---

## Q3. `null` বনাম `undefined`

```text
undefined → value assign হয়নি / absent
null      → intentionally empty
```

# 40.44 Interview — Shallow vs Deep Copy

Shallow:

```javascript
const copy = {
  ...user
};
```

Nested reference share করতে পারে।

Deep:

```javascript
const copy =
  structuredClone(user);
```

Nested structures-এর independent copy তৈরি করতে পারে, supported data types-এর সীমার মধ্যে।

# 40.45 Interview — `this`

`this`-এর value context-এর উপর নির্ভর করে।

Object method:

```javascript
const user = {
  name: "Ripon",

  greet() {
    console.log(this.name);
  }
};
```

Arrow function-এর নিজস্ব `this` binding নেই; এটি surrounding lexical `this` ব্যবহার করে।

🔥 Interview-এ এটি খুব common।

# 40.58 Coding Interview Problem 5 — Frequency Counter

```javascript
function countFrequency(items) {
  const result = {};

  for (const item of items) {
    result[item] =
      (result[item] || 0) + 1;
  }

  return result;
}

console.log(
  countFrequency([
    "a",
    "b",
    "a",
    "c",
    "a"
  ])
);
```

Output:

```text
{
  a: 3,
  b: 1,
  c: 1
}
```
