# 26.1 Scope কী?

**Scope** হলো কোনো variable কোথা থেকে access করা যাবে তার সীমা।

JavaScript-এ প্রধানত:

```text
Global Scope
Function Scope
Block Scope
Module Scope
```

Example:

```javascript
let name = "Ripon";

function greet() {
    console.log(name);
}

greet();
```

### Output

```text
Ripon
```

কারণ `greet()` function তার বাইরের scope-এর `name` access করতে পারছে।

---

# 26.2 Lexical Scope

JavaScript-এ function **যেখানে লেখা হয়েছে**, সেই জায়গার scope-এর ওপর তার access নির্ভর করে।

এটাকে বলা হয়:

> **Lexical Scope**

Example:

```javascript
const name = "Ripon";

function outer() {

    function inner() {
        console.log(name);
    }

    inner();
}

outer();
```

### Output

```text
Ripon
```

`inner()` তার parent scope এবং তার বাইরের scope থেকে variable খুঁজে নেয়।

---

# 26.3 Scope Chain

যখন JavaScript কোনো variable খুঁজে, তখন সাধারণত:

```text
Current Scope
      ↓
Parent Scope
      ↓
Grandparent Scope
      ↓
Global Scope
```

এভাবে খুঁজতে থাকে।

Example:

```javascript
const a = 10;

function outer() {
    const b = 20;

    function inner() {
        const c = 30;

        console.log(a);
        console.log(b);
        console.log(c);
    }

    inner();
}

outer();
```

### Output

```text
10
20
30
```

> **Closure হলো এমন একটি function, যা তার lexical scope-এর variable-গুলোকে মনে রাখতে পারে, এমনকি outer function execution শেষ হয়ে যাওয়ার পরেও।**

সহজভাবে:

```text
Outer Function
      ↓
Inner Function
      ↓
Inner function remembers outer variables
```

# 26.9 Private Variable with Closure

```javascript
function createAccount(initialBalance) {

    let balance = initialBalance;

    return {
        deposit(amount) {
            balance += amount;
        },

        withdraw(amount) {
            if (amount <= balance) {
                balance -= amount;
            }
        },

        getBalance() {
            return balance;
        }
    };
}
```

এখন:

```javascript
const account = createAccount(1000);

account.deposit(500);

console.log(account.getBalance());
```

### Output

```text
1500
```

কিন্তু:

```javascript
console.log(account.balance);
```

### Output

```text
undefined
```

কারণ `balance` directly accessible নয়।

# 26.23 IIFE কেন ব্যবহার করা হতো?

আগে JavaScript-এ module system শক্তিশালী হওয়ার আগে global namespace pollution এড়াতে IIFE অনেক ব্যবহার করা হতো।

Example:

```javascript
(function() {

    const secret = "12345";

    console.log(secret);

})();
```

বাইরে:

```javascript
console.log(secret);
```

### Output

```text
ReferenceError
```

কারণ `secret` IIFE-এর ভিতরের scope-এ আছে।

বর্তমানে **ES Modules** অনেক ক্ষেত্রে এই কাজের আরও ভালো solution।

# 26.26 Closure vs IIFE

| Closure                            | IIFE                         |
| ---------------------------------- | ---------------------------- |
| Scope মনে রাখে                     | Immediately execute হয়       |
| সাধারণত returned function দেখা যায় | Function immediately run করে |
| Private state তৈরি করতে পারে       | Private scope তৈরি করতে পারে |
| Long-lived হতে পারে                | একবার execute হওয়া common    |
| `createCounter()` example          | `(function(){})()`           |

একটি গুরুত্বপূর্ণ বিষয়:

> **IIFE এবং Closure একই জিনিস নয়।**

IIFE হলো execution pattern।

Closure হলো lexical environment ধরে রাখার behavior।

একটি IIFE closure তৈরি করতেও পারে।

# 26.32 Partial Application

Partial application হলো কিছু argument আগে দিয়ে একটি নতুন function তৈরি করা।

```javascript
console.log(multiplyBy2(3, 4));
```

### Output

```text

```

```text

↓

↓

↓
```

# 26.37 `pipe()`

`pipe()` সাধারণত left-to-right।

```javascript
const pipe = (...functions) => value =>
    functions.reduce(
        (result, fn) => fn(result),
        value
    );
```

ব্যবহার:

```javascript
const process = pipe(
    double,
    add10,
    square
);

```

### Output

```text

```

# 26.38 `compose()` vs `pipe()`

```text
compose:
right → left

pipe:
left → right
```

Example:

```javascript
compose(square, add10, double)
```

Conceptually:

```text
double → add10 → square
```

আর:

```javascript
pipe(double, add10, square)
```

সরাসরি:

```text
double → add10 → square
```

# 26.39 Memoization

**Memoization** হলো কোনো expensive function-এর result cache করে রাখা।

ধরো:

```javascript
function square(n) {
    console.log("Calculating...");
    return n * n;
}
```

একই input বারবার দিলে বারবার calculation হচ্ছে।

Memoization দিয়ে:

```javascript
function memoize(fn) {

    const cache = new Map();

    return function(value) {

        if (cache.has(value)) {
            return cache.get(value);
        }

        const result = fn(value);

        cache.set(value, result);

        return result;
    };
}
```

ব্যবহার:

```javascript
const memoizedSquare = memoize(n => {
    console.log("Calculating...");
    return n * n;
});

console.log(memoizedSquare(5));
console.log(memoizedSquare(5));
```

### Output

```text
Calculating...
25
25
```

দ্বিতীয়বার calculation হয়নি।

# 26.42 Decorator Pattern

একটি function-এর মূল behavior না বদলে তার চারপাশে additional behavior যোগ করা যায়।

```javascript
function greet(name) {
    return `Hello ${name}`;
}
```

Decorator:

```javascript
function logFunction(fn) {

    return function(...args) {

        console.log("Function called");

        const result = fn(...args);

        console.log("Function finished");

        return result;
    };
}
```

ব্যবহার:

```javascript
const loggedGreet = logFunction(greet);

console.log(loggedGreet("Ripon"));
```

### Output

```text
Function called
Function finished
Hello Ripon
```

# 26.45 Debouncing

Debouncing খুব গুরুত্বপূর্ণ web development concept।

ধরো search box:

```text
User types:

R
Ri
Rip
Ripo
Ripon
```

প্রতিটি keypress-এ API call করলে:

```text
5 keystrokes
↓
5 API requests
```

এটা unnecessary হতে পারে।

Debounce বলে:

> User typing থামানোর পর function execute করো।

Basic implementation:

```javascript
function debounce(fn, delay) {

    let timer;

    return function(...args) {

        clearTimeout(timer);

        timer = setTimeout(() => {
            fn(...args);
        }, delay);

    };
}
```


দ্রুত type করলে previous timers cancel হবে।

একবার execute হতে পারে।

# 26.47 Throttling

**Throttling** মানে নির্দিষ্ট সময়ের মধ্যে function সর্বোচ্চ একটি নির্দিষ্ট frequency-তে চালানো।

যেমন scroll event:

```text
User scroll করছে খুব দ্রুত
↓
অনেক scroll events
↓
Throttle
↓
নির্দিষ্ট interval-এ function
```

Basic:

```javascript
function throttle(fn, delay) {

    let waiting = false;

    return function(...args) {

        if (waiting) return;

        fn(...args);

        waiting = true;

        setTimeout(() => {
            waiting = false;
        }, delay);
    };
}
```

---

# 26.48 Debounce vs Throttle

| Debounce                | Throttle                     |
| ----------------------- | ---------------------------- |
| শেষ event-এর পর execute | নির্দিষ্ট interval-এ execute |
| Search input            | Scroll                       |
| Resize শেষে             | Mouse movement               |
| Typing                  | Continuous events            |

সহজভাবে:

```text
Debounce:
"থামলে কাজ করো"

Throttle:
"চলতে থাকলেও নির্দিষ্ট সময় পরপর কাজ করো"
```

# 26.52 Closure Memory Consideration

Closure outer variables ধরে রাখতে পারে।

তাই unnecessary বড় data ধরে রাখলে memory usage বাড়তে পারে।

Example:

```javascript

    const hugeData = new Array(1000000).fill("data");

    return function() {
        console.log(hugeData.length);

```

Returned function `hugeData`-এর reference ধরে রাখছে।

তাই closure ব্যবহার করার সময়:

> প্রয়োজনের চেয়ে বেশি data unnecessarily ধরে রাখা উচিত নয়।
