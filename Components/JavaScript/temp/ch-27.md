# 27.1 — প্রথমে একটা সমস্যা বুঝি

ধরো আমাদের কাছে:

```javascript
const numbers = [10, 20, 30, 40];
```

আমরা লিখতে পারি:

```javascript
for (const number of numbers) {
    console.log(number);
}
```

Output:

```text
10
20
30
40
```

কিন্তু প্রশ্ন হলো:

> JavaScript কীভাবে জানে যে array-এর কোন value আগে দিতে হবে এবং কোনটা পরে দিতে হবে?

এর পেছনে আছে **Iterator**।

# 27.5 — Iterator কী?

Iterator হলো এমন একটি object যেটা sequentially values provide করে।

একটি iterator-এর মূল method:

```javascript
next()
```

Example:

```javascript
const numbers = [10, 20, 30];

const iterator = numbers[Symbol.iterator]();

console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());
```

Output:

```text
{ value: 10, done: false }
{ value: 20, done: false }
{ value: 30, done: false }
{ value: undefined, done: true }
```

# 🧠 `next()` কী return করে?

প্রতিবার `next()` একটি object return করে:

```javascript

    value: ...,
    done: ...

```

দুটি property:

| Property | অর্থ                     |
| -------- | ------------------------ |
| `value`  | বর্তমান value            |
| `done`   | iteration শেষ হয়েছে কিনা |

# 27.7 — Iterator Manually চালানো

```javascript
const numbers = [100, 200, 300];

const iterator = numbers[Symbol.iterator]();

let result = iterator.next();

while (!result.done) {

    console.log(result.value);

    result = iterator.next();
}
```

Output:

```text
100
200
300
```

অর্থাৎ `for...of` মূলত এই ধরনের iteration mechanism ব্যবহার করে।

# 27.8 — `for...of` কীভাবে কাজ করে?

তুমি লিখলে:

```javascript
for (const number of numbers) {
    console.log(number);
}
```

Conceptually:

```text
numbers
   ↓
Symbol.iterator
   ↓
iterator
   ↓
next()
   ↓
value
   ↓
next()
   ↓
value
   ↓
done === true
```

অর্থাৎ:

```javascript
for...of
```

এর পেছনে iterator protocol কাজ করছে।

# 27.11 — Custom Iterator

এখন আমরা নিজের Iterator বানাবো।

ধরো:

```text
10
20
30
```

আমরা চাই object-টাকে `for...of` দিয়ে iterate করতে।

```javascript
const numbers = {

    values: [10, 20, 30],

    [Symbol.iterator]() {

        let index = 0;

        return {

            next: () => {

                if (index < this.values.length) {

                    return {
                        value: this.values[index++],
                        done: false
                    };

                }

                return {
                    value: undefined,
                    done: true
                };
            }
        };
    }
};
```

এখন:

```javascript
for (const number of numbers) {
    console.log(number);
}
```

Output:

```text
10
20
30
```

# 27.12 — Custom Iterator সহজ Version

একটু ছোট করে:

```javascript
const range = {

    start: 1,
    end: 5,

    [Symbol.iterator]() {

        let current = this.start;

        return {

            next: () => {

                if (current <= this.end) {

                    return {
                        value: current++,
                        done: false
                    };

                }

                return {
                    done: true
                };
            }
        };
    }
};

for (const number of range) {
    console.log(number);
}
```

Output:

```text
1
2
3
4
5
```

# 27.14 — Generator কী?

# 27.16 — `yield` কী?

`yield` generator-এর execution pause করে।

```javascript
function* test() {

    console.log("Step 1");

    yield "Hello";

    console.log("Step 2");

    yield "World";

    console.log("Step 3");

}
```

এখন:

```javascript
const generator = test();

console.log(generator.next());
console.log(generator.next());
console.log(generator.next());
```

Output roughly:

```text

{ value: "Hello", done: false }

Step 2
{ value: "World", done: false }

Step 3
{ value: undefined, done: true }
```

# 27.22 — `next(value)`

এটি Generator-এর advanced feature।

`next()` দিয়ে generator-এ value পাঠানো যায়।

```javascript
function* test() {

    const value = yield "Enter a value";

    yield `You entered: ${value}`;

}

const generator = test();

console.log(generator.next());
console.log(generator.next(100));
```

Output:

```text
{ value: "Enter a value", done: false }
{ value: "You entered: 100", done: false }
```

### কীভাবে কাজ করছে?

প্রথম:

```javascript
generator.next()
```

Generator চলে:

```javascript
const value = yield "Enter a value";
```

এখানে pause।

তারপর:

```javascript
generator.next(100)
```

এর `100` গিয়ে:

```javascript
value
```

এর মধ্যে ঢুকে যায়।

# 27.28 — Lazy Evaluation

এটি Iterators/Generators-এর সবচেয়ে গুরুত্বপূর্ণ practical concept-এর একটি।

**Lazy Evaluation** মানে:

> প্রয়োজন হওয়ার আগে value তৈরি না করা।

ধরো 1 থেকে 1 billion পর্যন্ত numbers।

Normal array:

```javascript
const numbers = [];

for (let i = 1; i <= 1_000_000_000; i++) {
    numbers.push(i);
}
```

এখানে huge memory লাগবে।

Generator:

```javascript
function* numbers() {

    let i = 1;

    while (true) {

        yield i++;

    }

}
```

এখানে সব number memory-তে একসাথে রাখা হচ্ছে না।

যখন দরকার:

```javascript
generator.next();
```

তখন value তৈরি হচ্ছে।

# 27.32 — Custom Iterable Class

Class-এর সাথে Iterator combine করা যায়।

```javascript
class NumberRange {

    constructor(start, end) {

        this.start = start;
        this.end = end;

    }

    *[Symbol.iterator]() {

        for (
            let number = this.start;
            number <= this.end;
            number++
        ) {

            yield number;

        }

    }

}

const range = new NumberRange(1, 5);

for (const number of range) {

    console.log(number);

}
```

Output:

```text
1
2
3
4
5
```

এখানে:

```javascript
*[Symbol.iterator]()
```

একটি generator method।

# 27.33 — Generator Method

```javascript
class UserList {
```

# 27.34 — Iterator vs Generator

| Iterator                                  | Generator                        |
| ----------------------------------------- | -------------------------------- |
| `next()` manually implement করতে হয়       | `yield` ব্যবহার করা যায়          |
| বেশি code লাগে                            | কম code                          |
| `Symbol.iterator` manually লিখতে হতে পারে | generator automatically iterable |
| More control                              | Easier syntax                    |
| Low-level concept                         | Higher-level abstraction         |

### Iterator:

```javascript
const iterator = {

    next() {
        return {
            value: 1,
            done: false
        };
    }

};
```

### Generator:

```javascript
function* generator() {

    yield 1;

}
```

Generator অনেক ক্ষেত্রে iterator তৈরি করা সহজ করে।

# 27.35 — Iterable vs Iterator vs Generator

এটা অবশ্যই clear রাখতে হবে।

```text
Iterable
   │
   └── Symbol.iterator()
            │
            ↓
        Iterator
            │
            └── next()
                  │
                  ↓
             { value, done }
```

Generator:

```text
Generator Function
       ↓
Generator Object
       ↓
Iterable + Iterator
```

অর্থাৎ Generator object সাধারণত দুটোই:

> **Iterable + Iterator**

# 27.36 — কোনগুলো Iterable?

```javascript
    *[Symbol.iterator]() {

        yield this.name;
        yield this.age;

    }

};

for (const value of user) {

    console.log(value);

}
```

Output:

```text
Shariar
23
```

এখন object iterable হয়ে গেছে।

# 27.38 — Generator vs Normal Function

| Normal Function          | Generator                    |
| ------------------------ | ---------------------------- |
| `function`               | `function*`                  |
| `return`                 | `yield`                      |
| একবার execute            | Pause/resume                 |
| সাধারণত single result    | Multiple sequential results  |
| state execution শেষে শেষ | state preserve করে           |
| lazy sequence নয়         | lazy sequence তৈরি করতে পারে |

# 27.39 — Real-Life Example: API Pagination

ধরো API-এর data:

```text
/page=1
/page=2
/page=3
...
```

Conceptually:

```javascript
async function* fetchPages() {

    let page = 1;

    while (true) {

        const response =
            await fetch(`/api/users?page=${page}`);

        const data = await response.json();

        if (data.length === 0) {
            return;
        }

        yield data;

        page++;
    }

}
```

ব্যবহার:

```javascript
for await (const users of fetchPages()) {

    console.log(users);

}
```

এটি **Async Generator**।

এটা আমরা পরে Async JavaScript-এর সাথে আরও গভীরভাবে ব্যবহার করব।

## ⭐ সবচেয়ে গুরুত্বপূর্ণ ৫টি Concept

যদি Chapter 27 থেকে শুধু ৫টা জিনিস মনে রাখতে চাও:

```text
1️⃣ Iterable → Symbol.iterator
2️⃣ Iterator → next()
3️⃣ next() → { value, done }
4️⃣ Generator → function*
5️⃣ yield → value দেয় + execution pause করে
```

আর সবচেয়ে গুরুত্বপূর্ণ relationship:

> **`for...of` → Iterable → Iterator → `next()`**

এটা বুঝে ফেললে Chapter 27-এর মূল concept তোমার পরিষ্কার হয়ে যাবে।
