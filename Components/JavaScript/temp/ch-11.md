# 11.1 Prototype কী?

JavaScript-এর প্রতিটি সাধারণ object-এর পেছনে একটি **prototype object** থাকতে পারে।

সহজভাবে:

> **Prototype হলো এমন একটি object, যেখান থেকে অন্য object property ও method খুঁজে পেতে পারে।**

### 🏠 Real-life Example

ধরো, একটি বিশ্ববিদ্যালয়ের অনেক Student আছে।

প্রত্যেক Student-এর নিজের:

```text
name
id
department
```

আছে।

কিন্তু সবাই একই ধরনের কিছু কাজ করতে পারে:

```text
study()
attendClass()
takeExam()
```

প্রত্যেক Student object-এর মধ্যে আলাদাভাবে `study()` লিখে না রেখে একটি common জায়গায় রাখা যায়।

সেই common জায়গাটা prototype-এর মতো।

# 11.2 Prototype দেখব কীভাবে?

JavaScript-এ:

```javascript
const user = {
    name: "Ripon"
};

console.log(Object.getPrototypeOf(user));
```

### Output:

```text
{ ... }
```

এটি `user` object-এর prototype দেখাবে।

আরেকটি common syntax:

```javascript
console.log(user.__proto__);
```

তবে `__proto__` legacy/accessor হিসেবে পরিচিত। শেখার সময় দেখতে পারো, কিন্তু code-এ prototype নিয়ে কাজ করার জন্য সাধারণত:

```javascript
Object.getPrototypeOf()
```

এবং

```javascript
Object.setPrototypeOf()
```

ব্যবহার করা ভালো।

# 11.3 Prototype Chain কী?

এটাই খুব গুরুত্বপূর্ণ। 🔥

যখন JavaScript কোনো object-এর মধ্যে কোনো property বা method খুঁজে পায় না, তখন সে তার prototype-এর মধ্যে খোঁজে।

সেখানেও না পেলে prototype-এর prototype-এ খোঁজে।

এভাবে চলতে থাকে।

এটিই:

> **Prototype Chain**

### Example

```javascript
const user = {
    name: "Ripon"
};

console.log(user.toString());
```

আমরা `user` object-এর মধ্যে নিজেরা `toString()` লিখিনি।

তবুও কাজ করছে।

কেন?

কারণ JavaScript roughly এভাবে খুঁজছে:

```text
user
 ↓
Object.prototype
 ↓
null
```

`user`-এ `toString()` নেই।

তাই:

```text
Object.prototype
```

এ গিয়ে `toString()` পেয়ে যায়।

---

# 11.4 Prototype Chain-এর Visual Idea

```text
user
 │
 │ prototype
 ▼
Object.prototype
 │
 │ prototype
 ▼
null
```

এখানে:

```javascript
Object.getPrototypeOf(user)
```

দিলে `Object.prototype` পাওয়া যাবে।

আর:

```javascript
Object.getPrototypeOf(Object.prototype)
```

দিলে:

```javascript
null
```

এটি prototype chain থেকে পাওয়া।

# 11.13 `Object.create()`

`Object.create()` দিয়ে নির্দিষ্ট prototype ব্যবহার করে নতুন object তৈরি করা যায়।


```text
Animal is eating
```

`dog`-এর নিজের property:

```text
name
```

আর inherited method:

```text
eat()
```

# 11.17 `new` কী করে?

🔥 `new` keyword-এর কাজ বোঝা খুব গুরুত্বপূর্ণ।

যখন লিখি:

```javascript
const student1 = new Student("Ripon", "CSE");
```

Conceptually JavaScript roughly:

### Step 1

নতুন empty object তৈরি করে।

```javascript
{}
```

### Step 2

নতুন object-এর prototype সেট করে:

```text
Student.prototype
```

### Step 3

`this` নতুন object-কে refer করে।

```javascript
this.name = "Ripon";
```

### Step 4

Constructor-এর মাধ্যমে object initialize করে।

### Step 5

নতুন object return করে।

Conceptually:

```text
new Student()
      ↓
new object
      ↓
prototype = Student.prototype
      ↓
this = new object
      ↓
return object
```

# 11.21 Prototype Method-এর Memory Advantage

ধরো:


কিন্তু prototype-এ:

```text

student3 ──┘
```

# 11.26 Prototype Inheritance Example

```javascript
function Person(name) {
    this.name = name;
}

Person.prototype.sayHello = function() {
    console.log("Hello, I am " + this.name);
};

function Student(name, department) {
    Person.call(this, name);
    this.department = department;
}

Student.prototype = Object.create(Person.prototype);

Student.prototype.constructor = Student;

Student.prototype.study = function() {
    console.log(this.name + " is studying " + this.department);
};

const student = new Student("Ripon", "CSE");

student.sayHello();
student.study();
```

### Output

```text
Hello, I am Ripon
Ripon is studying CSE
```

এখানে:

```text
student
 ↓
Student.prototype
 ↓
Person.prototype
 ↓
Object.prototype
 ↓
null
```

এটাই prototype-based inheritance-এর একটি traditional pattern।

# 11.27 `Person.call(this, name)` কী?

এই line:

```javascript
Person.call(this, name);
```

`Person` constructor-কে current `this` context দিয়ে call করছে।

`Person`-এর মধ্যে:

```javascript
this.name = name;
```

ছিল।

তাই Student-এর object-এর মধ্যেও:

```javascript
name
```

set হচ্ছে।

---

# 11.28 `Object.create(Person.prototype)` কেন?

এই line:

```javascript
Student.prototype = Object.create(Person.prototype);
```

এর মাধ্যমে বলা হচ্ছে:

> Student-এর prototype হবে এমন একটি object, যার prototype হলো Person.prototype।

অর্থাৎ:

```text
Student.prototype
       ↓
Person.prototype
```

---

# 11.29 কেন `constructor` আবার সেট করা হয়?

এই line:

```javascript
Student.prototype.constructor = Student;
```

কারণ:

```javascript
Student.prototype = Object.create(Person.prototype);
```

করার পর `constructor` reference বদলে যেতে পারে।

তাই explicitly:

```javascript
Student.prototype.constructor = Student;
```

দেওয়া হয়।

# 11.34 Inheritance with `extends`

Modern JavaScript-এ inheritance সহজভাবে:


# 11.40 Prototype Pollution সম্পর্কে Basic ধারণা

এটি security-related গুরুত্বপূর্ণ concept।

যদি untrusted user input দিয়ে object prototype modify করার সুযোগ তৈরি হয়, application-এর অন্য object-ও প্রভাবিত হতে পারে।

Conceptually dangerous pattern:

```javascript
Object.prototype.isAdmin = true;
```

এখন:

```javascript
const user = {};

console.log(user.isAdmin);
```

### Output

```text
true
```

যদিও `user`-এর মধ্যে আমরা:

```javascript
isAdmin
```

লিখিনি।

কারণ এটি:

```text
Object.prototype
```

থেকে এসেছে।

⚠️ বাস্তব application-এ এভাবে built-in prototypes modify করা উচিত নয়।
