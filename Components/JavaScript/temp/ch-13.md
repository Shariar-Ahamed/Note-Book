# 13.6 `getMonth()` — গুরুত্বপূর্ণ ⚠️

```javascript

console.log(date.getMonth());
```

`getMonth()` **0-based**।

```text

February  → 1
March     → 2
...
December  → 11
```

তাই:

```javascript
const month = new Date().getMonth() + 1;
```

ব্যবহার করলে সাধারণ 1–12 month number পাওয়া যায়।

# 13.38 Random Integer Function

```javascript
function randomNumber(min, max) {
    return Math.floor(
        Math.random() * (max - min + 1)
    ) + min;
}

console.log(randomNumber(1, 100));
```

Output হতে পারে:

```text
47
```

# 13.39 Real-Life Example — OTP-like Number


# 13.92 সবগুলো একসাথে — Mini Project

ধরো একটি product:

```javascript
const product = {
    name: "Laptop",
    price: 75999.567,
    discount: 10
};
```

আমরা:

1. Discount calculate করব
2. 2 decimal-এ round করব
3. Currency format করব
4. Current date দেখাব

```javascript
const product = {
    name: "Laptop",
    price: 75999.567,
    discount: 10
};

const discountAmount =
    product.price *
    product.discount /
    100;

const finalPrice =
    product.price - discountAmount;

const formattedPrice =
    new Intl.NumberFormat("en-BD", {
        style: "currency",
        currency: "BDT"
    }).format(finalPrice);

console.log("Product:", product.name);
console.log("Price:", formattedPrice);
console.log("Date:", new Date().toLocaleDateString());
```

Possible output:

```text
Product: Laptop
Price: BDT 68,399.61
Date: 9/16/2026
```

Formatting browser/locale অনুযায়ী কিছুটা ভিন্ন হতে পারে।
