8.1 String কী?

সহজভাবে:

Core Definition: String = এক বা একাধিক character-এর collection যা text represent করে।
Real-Life Example

8.21 Template Literals

Modern JavaScript-এ String তৈরি করার সবচেয়ে useful featureগুলোর একটি হলো:
