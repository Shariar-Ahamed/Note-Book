40.9 DRY

DRY = Don't Repeat Yourself ধরো:

JAVASCRIPT SourceJAVASCRIPT
console.log("User logged in");
console.log("User logged in");
console.log("User logged in");

এভাবে repeated logic থাকলে function:

JAVASCRIPT SourceJAVASCRIPT
function logLogin() {
  console.log("User logged in");
}

তারপর:

JAVASCRIPT SourceJAVASCRIPT
logLogin();
logLogin();
logLogin();
🔹 তবে একটা গুরুত্বপূর্ণ বিষয়

DRY মানে সব duplicate-looking code জোর করে abstraction করা নয়। অতিরিক্ত abstraction code আরও complex করতে পারে।
