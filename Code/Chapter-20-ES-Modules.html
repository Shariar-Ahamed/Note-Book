Part 01 — Module Architecture & The ES Modules Standard (20.1 – 20.8)
20.1 Module কী?

Module হলো JavaScript code-এর একটি আলাদা file, যেখানে নির্দিষ্ট functionality রাখা হয় এবং প্রয়োজন হলে অন্য file-এ export / import করা যায়।

সহজভাবে:

একটা বড় Project ↓ ┌─────┼─────┐ ↓ ↓ ↓ auth cart utils .js .js .js

প্রতিটি file নিজের কাজ করবে।

20.51 Module Cache / Reuse

একই module একাধিক জায়গায় import করলে environment সাধারণত module-টিকে বারবার নতুন করে execute না করে module instance reuse করে।

Example:

app.js ──┐ ├──→ config.js cart.js ─┘
