# 📘 JavaScript Complete Book — Chapter 14

# Error Handling & Debugging — Error মোকাবিলা ও Debugging

এখন আমরা JavaScript-এর খুব গুরুত্বপূর্ণ একটি অংশ শিখব: **Error Handling এবং Debugging**।

বাস্তব জীবনের application-এ user ভুল input দিতে পারে, API fail করতে পারে, কোনো variable ভুল হতে পারে, server response না-ও আসতে পারে। তখন program যেন পুরোপুরি crash না করে এবং developer যেন সমস্যাটা খুঁজে বের করতে পারে—এই কাজের জন্য Error Handling ও Debugging ব্যবহার করা হয়।

---

# 14.1 Error কী? — Error কী জিনিস?

**Error** হলো program-এর এমন একটি সমস্যা যার কারণে JavaScript প্রত্যাশিতভাবে কাজ করতে পারে না।

### Real-Life Example

ধরো তুমি একটি ATM-এ গেলে:

* Account number ভুল → সমস্যা
* PIN ভুল → সমস্যা
* Balance কম → সমস্যা
* ATM server unavailable → সমস্যা

Programming-এও একই ধরনের সমস্যা হয়।

```javascript
let age = 20;

console.log(age);
```

এখানে কোনো সমস্যা নেই।

কিন্তু:

```javascript
console.log(username);
```

এখানে `username` declare করা হয়নি।

Output:

```text
ReferenceError: username is not defined
```

# 14.2 Error বনাম Exception

দুটো শব্দ অনেক সময় একই অর্থে ব্যবহার করা হলেও conceptually:

* **Error** → program-এর সমস্যা
* **Exception** → runtime-এ এমন একটি exceptional condition যা আমরা handle করতে পারি

উদাহরণ:

```javascript
let result = 10 / 0;

console.log(result);
```

Output:

```text
Infinity
```

এটা error নয়।

কিন্তু:

```javascript
throw new Error("Something went wrong");
```

এখানে আমরা ইচ্ছাকৃতভাবে একটি exception throw করেছি।

# 14.3 Common JavaScript Errors

JavaScript-এ কয়েক ধরনের গুরুত্বপূর্ণ built-in error আছে।

| Error            | Meaning                                              |
| ---------------- | ---------------------------------------------------- |
| `SyntaxError`    | Code-এর syntax ভুল                                   |
| `ReferenceError` | এমন variable/reference ব্যবহার করা হয়েছে যা নেই      |
| `TypeError`      | ভুল type-এর operation                                |
| `RangeError`     | Valid range-এর বাইরে value                           |
| `URIError`       | URI-related ভুল                                      |
| `EvalError`      | `eval()`-related error; modern code-এ খুব কম ব্যবহৃত |
| `AggregateError` | একাধিক error একসাথে represent করতে ব্যবহৃত           |

# 14.4 SyntaxError

Syntax ভুল হলে `SyntaxError` হয়।

```javascript
if (true {
    console.log("Hello");
}
```

Output:

```text
SyntaxError
```

কারণ:

```javascript
if (true)
```

এর পরে `)` missing।

সঠিক:

```javascript
if (true) {
    console.log("Hello");
}
```

Output:

```text
Hello
```

### সহজভাবে

Compiler/JavaScript engine বলতে পারে:

> "তোমার code-এর grammar ঠিক নেই।"

# 14.5 ReferenceError

যে variable exist করে না সেটি access করলে `ReferenceError` হয়।

```javascript
console.log(userName);
```

Output:

```text
ReferenceError: userName is not defined
```

সঠিক:

```javascript
let userName = "Shariar";

console.log(userName);
```

Output:

```text
Shariar
```

### Real-Life Example

তুমি বললে:

> "আমাকে Rahim-এর phone number দাও।"

কিন্তু তোমার contact list-এ Rahim-এর কোনো record নেই।

Programming-এ একইভাবে unknown variable → `ReferenceError`।

# 14.6 TypeError

ভুল data type-এর ওপর এমন operation করলে `TypeError` হতে পারে।

```javascript
let user = null;

console.log(user.name);
```

Output:

```text
TypeError
```

কারণ `null`-এর মধ্যে `name` access করা যাচ্ছে না।

আরেকটি example:

```javascript
let age = 20;

age();
```

Output:

```text
TypeError: age is not a function
```

কারণ `age` একটি number, function নয়।

# 14.7 RangeError

কোনো value valid range-এর বাইরে গেলে `RangeError` হতে পারে।

```javascript
let number = 10;

console.log(number.toFixed(101));
```

এখানে decimal digits-এর valid range-এর বাইরে value দেওয়া হয়েছে।

Output:

```text
RangeError
```

আরেকটি example:

```javascript
let arr = new Array(-5);
```

Output:

```text
RangeError
```

কারণ array length negative হতে পারে না।

# 14.11 `try...catch`

JavaScript-এ error handle করার সবচেয়ে গুরুত্বপূর্ণ system হলো:

```javascript
try {
    // risky code
} catch (error) {
    // error handling
}
```

### Example

```javascript
try {
    console.log(userName);
} catch (error) {
    console.log("Something went wrong!");
}
```

Output:

```text
Something went wrong!
```

এখানে program পুরোপুরি crash না করে `catch` block-এ চলে গেছে।

# 14.14 `finally`

`finally` block **error হোক বা না হোক**, সাধারণত execute হয়।

Syntax:

```javascript
try {

} catch (error) {

} finally {

}
```

Example:

```javascript
try {
    console.log("Trying...");
} catch (error) {
    console.log("Error!");
} finally {
    console.log("Finished!");
}
```

Output:

```text
Trying...
Finished!
```

Error হলে:

```javascript
try {
    console.log(userName);
} catch (error) {
    console.log("Error!");
} finally {
    console.log("Finished!");
}
```

Output:

```text
Error!
Finished!
```

# 14.20 Custom Error

নিজের application-এর জন্য custom error class তৈরি করা যায়।

```javascript
class ValidationError extends Error {

    constructor(message) {
        super(message);

        this.name = "ValidationError";
    }

}
```

এখন:

```javascript
throw new ValidationError("Email is invalid");
```

Output:

```text
ValidationError: Email is invalid
```

# 14.21 Custom Error ব্যবহার

```javascript
class ValidationError extends Error {
    constructor(message) {
        super(message);
        this.name = "ValidationError";
    }
}

function register(email) {

    if (!email.includes("@")) {
        throw new ValidationError("Invalid email");
    }

    console.log("Registration successful");
}

try {
    register("hello.com");
} catch (error) {
    console.log(error.name);
    console.log(error.message);
}
```

Output:

```text
ValidationError
Invalid email
```

# 14.23 Multiple Error Handling

একাধিক ধরনের error আলাদাভাবে handle করা যায়।

```javascript
try {

    let user = null;

    console.log(user.name);

} catch (error) {

    if (error instanceof TypeError) {
        console.log("Type problem!");

    } else if (error instanceof ReferenceError) {
        console.log("Reference problem!");

    } else {
        console.log("Unknown error!");
    }

}
```

Output:

```text
Type problem!
```

# 14.26 `finally` কখন বেশি ব্যবহার হয়?

`finally` সাধারণত cleanup operation-এর জন্য useful।

যেমন:

* Database connection cleanup
* File cleanup
* Loading state বন্ধ করা
* Resource release

Example:

```javascript
let loading = true;

try {
    console.log("Fetching data...");
} catch (error) {
    console.log("Error!");
} finally {
    loading = false;
    console.log("Loading finished");
}
```

Output:

```text
Fetching data...
Loading finished
```

# 14.40 Breakpoint

ধরো:

```javascript
function calculate() {

    let price = 100;
    let quantity = 3;

    console.log(total);

```

# 14.42 Call Stack


```text

three()
```

এটাকে **Call Stack** দিয়ে track করা যায়।

Error হলে stack trace দেখে বোঝা যায় কোন function chain-এর মাধ্যমে error এসেছে।

```javascript
function calculateTotal(price, quantity) {
```

# 14.54 Complete Mini Project — Student Registration

এখন সব concept একসাথে ব্যবহার করি।

```javascript
class ValidationError extends Error {

    constructor(message) {
        super(message);
        this.name = "ValidationError";
    }

}

function registerStudent(name, age, email) {

    if (!name) {
        throw new ValidationError("Name is required");
    }

    if (typeof age !== "number") {
        throw new TypeError("Age must be a number");
    }

    if (age < 18) {
        throw new ValidationError("Student must be at least 18");
    }

    if (!email.includes("@")) {
        throw new ValidationError("Invalid email");
    }

    return {
        name,
        age,
        email
    };
}

try {

    let student = registerStudent(
        "Shariar",
        23,
        "shariar@example.com"
    );

    console.table(student);

} catch (error) {

    console.error(error.name);
    console.error(error.message);

}
```

Output:

```text
name     Shariar
age      23
email    shariar@example.com
```
