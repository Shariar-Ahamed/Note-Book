### 📖 প্রতিটা Topic কীভাবে লেখা হবে?

ধরো আমরা **JavaScript `map()`** পড়ছি।

তাহলে format হবে এমন:

### `map()` Method

**English:**
`map()` creates a new array by applying a function to every element of an existing array.

**বাংলায়:**
`map()` একটি array-এর প্রতিটি element-এর উপর একই কাজ করে **নতুন একটি array তৈরি করে**।

**Real-life example:**
ধরো তোমার কাছে ৫ জন student's marks আছে। প্রত্যেকের mark ৫ করে বাড়াতে হবে। তখন একেকটা mark manually পরিবর্তন না করে `map()` ব্যবহার করতে পারো।

```javascript
const marks = [50, 60, 70, 80];

const updatedMarks = marks.map(function(mark) {
    return mark + 5;
});

console.log(updatedMarks);
```

**Output:**

```text
[55, 65, 75, 85]
```

**সহজভাবে বুঝলে:**

```text
50 → +5 → 55
60 → +5 → 65
70 → +5 → 75
80 → +5 → 85
```

তারপর একই example-টা modern JavaScript-এ:

```javascript
const marks = [50, 60, 70, 80];

const updatedMarks = marks.map(mark => mark + 5);

console.log(updatedMarks);
```

Output:

```text
[55, 65, 75, 85]
```

তারপর আমি বলব:

> 💡 **Important:** `map()` সাধারণত original array পরিবর্তন করে না; এটি একটি নতুন array return করে।

তারপর থাকবে:

**Common Mistake ❌**

```javascript
marks.map(mark => {
    mark + 5;
});
```

এখানে `return` করা হয়নি, তাই expected result পাওয়া যাবে না।

**Correct ✅**

```javascript
marks.map(mark => {
    return mark + 5;
});
```

অথবা:

```javascript
marks.map(mark => mark + 5);
```

### 🎯 আরেকটা গুরুত্বপূর্ণ বিষয়

আমি শুধু **syntax মুখস্থ করানোর মতো notes** বানাব না।

যেখানে দরকার সেখানে বুঝাব:

**"JavaScript ভিতরে আসলে কীভাবে কাজ করছে?"**

যেমন:

```javascript
console.log("A");

setTimeout(() => {
    console.log("B");
}, 0);

console.log("C");
```

Output কেন—

```text
A
C
B
```

হচ্ছে, সেটা **Call Stack → Web API → Callback Queue → Event Loop** পর্যন্ত বুঝাব।

একইভাবে:

```javascript
const user = {
    name: "Ripon",
    address: {
        city: "Dhaka"
    }
};

console.log(user.address.city);
```

থেকে শুরু করে পরে:

```javascript
console.log(user?.address?.city);
```

কেন দরকার, সেটাও real-world example দিয়ে দেখাব।
